# Домашнее задание: карточка пользователя

Соберите словарь с данными одного человека и выведите отчёт о нём.

## Задача

Создайте словарь `user` с ключами `name` (строка), `age` (целое),
`height` (дробное) и `is_student` (логическое). Затем выведите для каждого
ключа строку вида:

```
name: Мария (str)
```

То есть имя ключа, значение и тип значения в скобках. Тип берите из `type`.

## Как проверить себя

- Строк в выводе ровно четыре — по одной на ключ.
- В скобках стоит `str`, `int`, `float`, `bool`, а не `<class 'int'>`:
  у типа есть атрибут `__name__`.
- Добавление пятого ключа в словарь не требует правок в коде вывода — значит,
  вы перебрали словарь, а не написали четыре отдельных `print`.
- `is_student = False` печатается как `False`, а не пропускается: проверять
  значение на истинность здесь не нужно.
