# Шпаргалка по основам Python

## Переменные

```python
name = "Мария"     # str
age = 30            # int
height = 1.72       # float
is_student = False  # bool
```

## Типы данных

| Тип | Пример | Изменяемый |
| --- | --- | --- |
| `str` | `"текст"` | нет |
| `int` | `42` | нет |
| `float` | `3.14` | нет |
| `bool` | `True` | нет |
| `list` | `[1, 2, 3]` | да |
| `tuple` | `(1, 2, 3)` | нет |
| `dict` | `{"a": 1}` | да |

## Команды

```bash
python3 --version   # версия
python3 program.py  # запуск файла
python3             # интерактивный режим
```
