# Глоссарий

**Граф (graph)** — описание приложения в виде узлов и переходов между ними. Главная единица LangGraph: вы описываете граф, движок его исполняет.

**Узел (node)** — функция, которая получает состояние и возвращает словарь с изменёнными полями. Единица работы и единица сохранения.

**Ребро (edge)** — переход между узлами. Обычное ребро ведёт всегда в один узел, условное выбирает следующий узел функцией.

**Состояние (state)** — набор полей, которые узлы читают и пишут. Объявляется схемой (`TypedDict`, `dataclass` или Pydantic-модель) и определяет контракт между узлами.

**Редьюсер (reducer)** — функция, объединяющая текущее значение поля с обновлением от узла. Без редьюсера обновление заменяет значение, а параллельная запись в поле вызывает ошибку.

**`add_messages`** — стандартный редьюсер для истории сообщений: добавляет новые, заменяет существующие по совпадающему `id`, удаляет по `RemoveMessage`.

**Супершаг (super-step)** — один такт исполнения: движок запускает все готовые узлы, собирает их обновления и применяет разом. Узлы одного супершага не видят результатов друг друга.

**`Command`** — объект, которым узел одновременно обновляет состояние и выбирает следующий шаг. С `graph=Command.PARENT` передаёт управление в родительский граф.

**`Send`** — запуск узла с собственной полезной нагрузкой. Позволяет создать столько параллельных задач, сколько понадобилось на исполнении: основа map-reduce в графе.

**`defer`** — признак узла, который ждёт завершения всех ведущих в него веток и выполняется один раз. Нужен узлам-сборщикам.

**Лимит шагов (`recursion_limit`)** — максимум супершагов за запуск; предохранитель от бесконечного цикла, а не механизм управления. В langgraph 1.2.11 по умолчанию 10007.

**Инструмент (tool)** — функция, которую модель может попросить вызвать. Её описание и имена аргументов попадают в промпт и влияют на выбор.

**ReAct-цикл** — схема работы агента: модель решает, звать ли инструмент; инструмент исполняется; результат возвращается модели; так до готового ответа.

**`ToolNode`** — готовый узел, исполняющий все вызовы инструментов из последнего сообщения модели и возвращающий по одному `ToolMessage` на каждый.

**`ToolRuntime`** — контекст исполнения, доступный инструменту: состояние графа, контекст запуска, хранилище, идентификатор вызова, канал событий.

**Контекст запуска (context)** — неизменяемые данные, заданные на один запуск: идентификатор пользователя, права, подключения. В отличие от состояния, не меняется узлами и не попадает в снимок.

**Чекпойнтер (checkpointer)** — хранилище снимков состояния. Делает возможными продолжение после сбоя, паузы для человека и историю выполнения.

**Снимок (checkpoint, `StateSnapshot`)** — сохранённое состояние после супершага вместе с планом: какие узлы должны выполниться дальше и какие прерывания активны.

**Нить (thread)** — последовательность снимков с общим `thread_id`; один разговор или один прогон.

**`durability`** — режим записи снимков: `sync` (до следующего шага), `async` (параллельно следующему шагу, по умолчанию), `exit` (только при завершении).

**Путешествие во времени (time travel)** — запуск графа от старого снимка: передаётся его конфигурация и вход `None`.

**Store (долговременная память)** — хранилище данных вне нити, с иерархическими пространствами имён и, при желании, семантическим поиском. Место для выводов агента о пользователе.

**Прерывание (`interrupt`)** — остановка графа с передачей значения человеку и продолжением через `Command(resume=...)`. Узел после возобновления выполняется с начала.

**Статическая пауза (`interrupt_before` / `interrupt_after`)** — остановка перед узлом или после него, заданная при компиляции. Ничего не передаёт человеку; инструмент отладки.

**Передача управления (handoff)** — переход работы к другому агенту или в родительский граф, обычно через `Command` или специальный инструмент.

**Подграф (subgraph)** — граф, подключённый как узел другого графа. Связывается по совпадающим полям состояния либо через функцию-обёртку.

**Супервизор** — агент, который распределяет работу между другими агентами и получает результат обратно.

**Рой (swarm)** — схема, в которой агенты передают управление друг другу напрямую, без центрального распорядителя.

**Functional API** — способ описать процесс обычной функцией: `@entrypoint` задаёт точку входа с чекпойнтером, `@task` помечает шаги, результаты которых сохраняются.

**Режим стрима (`stream_mode`)** — что отдавать из работающего графа: состояние целиком (`values`), изменения (`updates`), токены модели (`messages`), свои события (`custom`), диагностику (`tasks`, `checkpoints`, `debug`).

**`get_stream_writer`** — функция, которой узел или инструмент отправляет собственные события в поток.

**Кооперативный слив (drain)** — просьба прогону остановиться: текущий шаг доделывается, состояние сохраняется, запуск завершается ошибкой `GraphDrained` и может быть продолжен позже.

**`create_agent`** — фабрика LangChain, собирающая типовой ReAct-агент как готовый граф LangGraph.

**Middleware** — перехватчики вокруг вызовов модели и инструментов в готовом агенте: ограничения, сжатие истории, подтверждения, запасная модель.

**MCP (Model Context Protocol)** — протокол, по которому внешние серверы отдают инструменты, промпты и ресурсы; подключается адаптером как обычные инструменты.

**Ассистент (assistant)** — граф вместе с конфигурацией (промпт, модель, параметры контекста) и версией. Понятие сервера LangGraph.

**Модель-судья (LLM-as-judge)** — отдельный вызов модели для оценки ответа по заранее заданным критериям; используется в измерении качества.

**Трейс (trace)** — дерево вызовов одного запуска с промптами, ответами, инструментами и таймингами; основной инструмент разбора поведения агента.
