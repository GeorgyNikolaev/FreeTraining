# Домашнее задание: тесты и датасет для наставника

## Задача 1. Тесты без единого обращения к провайдеру

Соберите в `agent/tests/` набор тестов, покрывающий:

1. Маршрутизацию: вопрос по курсу → ветка ответа, посторонний → отказ.
2. Редьюсер источников: накопление без дублей и сброс.
3. ReAct-цикл на фейковой модели: инструмент вызван, результат вернулся, цикл завершился.
4. Соответствие вызовов и ответов: на каждый `tool_call` ровно один `ToolMessage` с тем же идентификатором.
5. Ошибку инструмента: запуск не падает, модель получает сообщение об ошибке.
6. Спойлер-гейт: без разрешения решение не выдаётся; произвольное значение в `resume` трактуется как безопасное.
7. Идемпотентность узла с прерыванием: побочное действие после `resume` выполняется один раз.

Подмену модели сделайте через контекст запуска, без патчей и глобальных переменных.

## Задача 2. Датасет

Соберите 20 случаев в `agent/evals/dataset.json`: вопросы по материалу (с указанием урока, на который наставник обязан сослаться), посторонние запросы, вопрос с ошибочной предпосылкой, вопрос про несуществующий урок и три решения ДЗ — верное, частично верное и пустое, с вашей разметкой по признакам.

## Задача 3. Прогон и метрики

Напишите `agent/evals/run.py`, который прогоняет граф по датасету и считает:

- долю ответов со ссылкой на существующий урок;
- долю верных отказов;
- согласие с вашей разметкой по проверке ДЗ, отдельно два вида промахов: пропустил ошибку и придрался к верному;
- средние вызовы модели и токены на ответ;
- долю ответов дольше 15 секунд.

Результат сохраняйте в файл с отметкой времени и версией промпта, чтобы прогоны можно было сравнивать.

## Задача 4. Судья и проверка судьи

Добавьте оценщика на модели с двумя бинарными критериями: «ответ опирается на текст урока» и «ответ не содержит готового решения». Разметьте десять ответов руками и посчитайте, в какой доле случаев судья совпал с вами.

## Как проверить себя

- Полный прогон тестов из задачи 1 проходит без ключей провайдера и укладывается в секунды. Если нужен ключ — где-то осталась настоящая модель.
- Тесты не проверяют текст ответа модели на вхождение слов. Такой тест ломается от смены версии модели и ничего не говорит о графе.
- Каждый тест использует свой `thread_id`. Запустите их в другом порядке: результат не должен измениться.
- В датасете есть случаи, на которых агент **сейчас** ошибается. Датасет, где всё зелёное, бесполезен: он не показывает, куда двигаться.
- Метрики сохраняются в файл, и два прогона можно сравнить командой. «Стало лучше» без чисел не считается.
- Судья совпадает с вашей разметкой хотя бы в восьми случаях из десяти. Если нет — правьте рубрику: скорее всего, критерий сформулирован размыто или судья не видит текста урока.
- Измените системный промпт узла `answer` (например, потребуйте отвечать короче) и прогоните датасет снова. Найдите случай, который от этого стал хуже: он почти наверняка есть, и это главный урок задания.
