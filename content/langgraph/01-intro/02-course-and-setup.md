# Как устроен курс и как поднять окружение

Этот урок отвечает на вопросы, ответов на которые в остальных уроках нет: что именно вы построите, в каком порядке, чего в курсе сознательно нет и что нужно сделать прямо сейчас, чтобы дальше шли не картинки, а работающий код.

## Что вы построите

Агента-наставника для этой платформы. Он растёт вместе с курсом: каждый модуль добавляет ему умение, которое опирается на изученное.

| Модуль | Что появляется у агента | Чему учит |
|---|---|---|
| 02 | Отвечает на вопрос по уроку, различая «вопрос по курсу» и «всё остальное» | состояние, узлы, рёбра, редьюсеры |
| 03 | Проверяет ДЗ сразу по всем критериям параллельно | циклы, `Command`, `Send`, обработка сбоев |
| 04 | Ходит в `content/` и в прогресс студента через инструменты | инструменты, ReAct-цикл, контекст исполнения |
| 05 | Помнит разговор после перезапуска и помнит студента между сессиями | чекпойнты, Postgres, долговременная память |
| 06 | Спрашивает разрешения, прежде чем выдать готовое решение | прерывания, человек в цикле |
| 07 | Отвечает потоком токенов в веб-интерфейсе | стриминг, SSE, интеграция с FastAPI |
| 08 | Раскладывается на подграфы и нескольких агентов под супервизором | композиция, мультиагентность, Functional API |
| 09 | Покрыт тестами, трейсится, измеряется на датасете | отладка, тестирование, оценка качества |
| 10 | Живёт как сервис и ходит по курсу в фоне, ища противоречия | деплой, фоновые прогоны, безопасность |

Код лежит в папке `agent/` этого репозитория. Уроки разбирают и показывают фрагменты, домашние задания просят дописать следующий кусок. **Домашние задания здесь не опциональны**: агент собирается именно в них, и модуль 07 предполагает, что модули 02–06 вы сделали руками.

## Как устроен курс

Модуль — это два-четыре урока, затем домашнее задание, затем тест на 4–8 вопросов. В конце курса — шпаргалка, глоссарий и экзамен на 20 вопросов.

Тесты проверяют не память на синтаксис: в первых модулях — понимание различий, дальше — выбор решения в конкретной ситуации, в последних — суждение о компромиссах. Проходной балл у модульных тестов 70, у экзамена 80.

Домашнее задание нигде не проверяется автоматически — вместо проверки у каждого есть раздел «Как проверить себя» с признаками рабочего результата и типичными ошибками.

## Чего в курсе нет

- **LangChain как таковой.** Модели, промпты, инструменты, структурированный вывод — отдельный курс. Здесь они используются как данность: мы берём `init_chat_model`, `@tool` и считаем, что читатель понимает, что такое вызов инструмента.
- **Промпт-инжиниринг.** Промпты в примерах рабочие, но не вылизанные; курс про исполнение, а не про формулировки.
- **Инфраструктура RAG.** Векторные базы, чанкинг, ранжирование — вне рамок. Наш агент ищет по файлам курса простым поиском, и этого достаточно для примера. Семантический поиск появится один раз — в долговременной памяти (модуль 05).
- **TypeScript-версия LangGraph.** API там устроен так же, но не идентичен; в курсе только Python. Часть возможностей (таймауты узлов, обработчики ошибок) на сентябрь 2026 вообще существует только в Python.
- **Тонкая настройка моделей и их выбор.** Берём одну модель через переменную окружения и не обсуждаем, какая лучше.

## Что нужно знать заранее

Курс не учит Python и не объясняет, как модель вызывает инструменты. Вам понадобится: свободный Python 3.12 с аннотациями типов (`TypedDict`, `Annotated`, `Literal`), асинхронный код (`async`/`await`, `asyncio.gather`), понимание tool calling и структурированного вывода, умение читать код FastAPI и SQL-запросы. Ключ к API провайдера моделей — в примерах OpenAI, но подойдёт любой поддерживаемый.

## Настройка окружения

Дальше — команды, которые нужно выполнить один раз. Выполняйте их из корня репозитория FreeTraining.

Создаём отдельный проект для агента (он не смешивается с бэкендом платформы — у них разные зависимости):

```bash
mkdir agent && cd agent
uv init --name freetraining-agent --python 3.12
uv add langgraph langchain langchain-openai
uv add --dev "langgraph-cli[inmem]"
```

На сентябрь 2026 это ставит `langgraph` 1.2.x и `langchain` 1.x. LangGraph требует Python 3.10 и выше, а CLI для локального сервера — 3.11 и выше; в репозитории уже используется 3.12, его и берём.

Ключ кладём в `agent/.env`:

```bash
OPENAI_API_KEY=sk-...
TUTOR_MODEL=openai:gpt-5.5
```

Названия моделей у провайдеров меняются часто — если строка `openai:gpt-5.5` не работает, подставьте актуальную из документации провайдера. Дальше в курсе модель везде берётся из этой переменной, так что менять её придётся в одном месте.

Теперь первый граф. Файл `agent/tutor/graph.py`:

```python
import os
from typing_extensions import TypedDict

from langchain.chat_models import init_chat_model
from langgraph.graph import START, END, StateGraph

model = init_chat_model(os.environ["TUTOR_MODEL"])


class State(TypedDict):
    question: str
    answer: str


def answer(state: State) -> State:
    reply = model.invoke(state["question"])
    return {"answer": reply.text}


builder = StateGraph(State)
builder.add_node("answer", answer)
builder.add_edge(START, "answer")
builder.add_edge("answer", END)

graph = builder.compile()
```

Файл `agent/tutor/__init__.py` оставьте пустым. Проверка:

```bash
uv run python -c "
from dotenv import load_dotenv; load_dotenv()
from tutor.graph import graph
print(graph.invoke({'question': 'Ответь одним словом: работает?'})['answer'])
"
```

Если ответ пришёл — окружение живо. (`python-dotenv` ставится вместе с зависимостями; если его нет — `uv add python-dotenv`.)

## Локальный сервер и Studio

Полезно с самого начала видеть граф картинкой и гонять его без своего интерфейса. Для этого рядом с `pyproject.toml` кладём `agent/langgraph.json`:

```json
{
  "dependencies": ["."],
  "graphs": {
    "tutor": "./tutor/graph.py:graph"
  },
  "env": "./.env"
}
```

И запускаем:

```bash
uv run langgraph dev
```

Команда поднимает локальный сервер на `http://127.0.0.1:2024` (его API-документация — на `/docs`) и печатает ссылку на Studio — веб-интерфейс на `smith.langchain.com`, который подключается к вашему локальному серверу. В нём видно схему графа, можно запустить его с любым входом и посмотреть, что происходило на каждом шаге. Для входа нужен аккаунт LangSmith; на сентябрь 2026 бесплатного тарифа для этого достаточно, но тарифы меняются — проверяйте. Сам сервер работает и без аккаунта, к нему можно ходить обычным HTTP-запросом.

Подробно про сервер, ассистентов и деплой — в модуле 10. Сейчас он нужен только как окно, через которое видно граф.

Держите `langgraph dev` запущенным на протяжении курса: он перечитывает код при изменениях, и каждый новый узел сразу появляется на схеме.
