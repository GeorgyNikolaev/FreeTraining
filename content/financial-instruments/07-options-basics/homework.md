# Домашнее задание: сканер арбитража в опционной доске

Расчёт на Python 3.12, около 50 минут. Результат — функция, которая по доске котировок находит все нарушения безарбитражных соотношений с учётом спредов, и разбор найденного.

## Исходные данные

Акция: бид 99,98, аск 100,02. Непрерывная ставка 12%, до экспирации 0,25 года. Опционы европейские, дивидендов нет. Одна котировка — один опцион на одну акцию.

```python
S_bid, S_ask = 99.98, 100.02
r, tau = 0.12, 0.25
strikes = [90, 95, 100, 105, 110]
calls = {90: (13.45, 13.53), 95: (10.30, 10.40), 100: (6.49, 6.57),
         105: (4.10, 4.18), 110: (2.42, 2.50)}        # (бид, аск)
puts = {90: (0.79, 0.87), 95: (1.82, 1.90), 100: (3.53, 3.61),
        105: (7.00, 7.10), 110: (9.17, 9.25)}
```

## Что сделать

1. Функция `scan(calls, puts, S_bid, S_ask, r, tau)` проверяет для каждого страйка и пары страйков:
   - паритет колл–пут в обе стороны;
   - нижние границы колла и пута;
   - монотонность цен по страйку;
   - ограничение на цену спреда: $C(K_1) - C(K_2) \le (K_2 - K_1)e^{-r\tau}$, для путов аналогично;
   - неотрицательность бабочек из трёх соседних страйков, отдельно для коллов и для путов.

   Покупка идёт по аску, продажа — по биду. Функция возвращает список нарушений: какая проверка, какие страйки, прибыль на единицу.
2. Для каждого нарушения — сделки, которые его реализуют, и проверка, что выплата неотрицательна при любой $S_T$ (например, на сетке от 0 до 200).
3. Сколько в доске **независимых** ошибок котировок? Какие нарушения — следствия одной и той же ошибки?
4. Ваш взгляд: к экспирации акция будет между 97 и 103. Выберите стратегию из котировок этой доски (без арбитражных ног), постройте её профиль прибыли и назовите максимальную прибыль, максимальный убыток и точки безубыточности.

## Как проверить себя

Сканер должен найти **четыре** нарушения:

| Проверка | Страйки | Сделки | Прибыль на единицу |
|---|---|---|---|
| Бабочка из коллов | 90 / 95 / 100 | Купить колл 90 по 13,53, купить колл 100 по 6,57, продать 2 колла 95 по 10,30 | 0,50 |
| Паритет | 95 | Продать колл по 10,30, купить пут по 1,90, купить акцию по 100,02, занять $95e^{-0{,}03} = 92{,}19$ | 0,57 |
| Паритет | 105 | Продать пут по 7,00, купить колл по 4,18, продать акцию по 99,98, разместить $105e^{-0{,}03} = 101{,}90$ | 0,90 |
| Бабочка из путов | 100 / 105 / 110 | Купить пут 100 по 3,61, купить пут 110 по 9,25, продать 2 пута 105 по 7,00 | 1,14 |

**Независимых ошибок две:**
- колл 95 дорог — отсюда бабочка из коллов и паритет на страйке 95;
- пут 105 дорог — отсюда паритет на страйке 105 и бабочка из путов.

Правильная цена колла 95 — около 9,67, пута 105 — около 6,04.

Признаки ошибок в сканере:
- **Нарушений больше десятка.** Вы, скорее всего, сравниваете середины котировок или покупаете по биду.
- **Бабочка из путов не найдена.** Проверка написана только для коллов.
- **Паритет на 105 найден с прибылью около 0,94.** Акция продана по аску вместо бида.

**По пункту 4.** Под взгляд «цена останется около 100» подходят бабочка или проданный стрэддл. Бабочки 95/100/105 из этой доски собрать без ошибочных котировок нельзя: колл 95 и пут 105 оценены неверно. Корректные варианты:
- **бабочка 90/100/110 из коллов:** купить колл 90 по 13,53 и колл 110 по 2,50, продать 2 колла 100 по 6,49. Стоимость 3,05. Максимальная прибыль $10 - 3{,}05 = 6{,}95$ при $S_T = 100$, максимальный убыток 3,05, безубыточность 93,05 и 106,95;
- **проданный стрэддл 100:** продать колл по 6,49 и пут по 3,53, получить 10,02. Прибыль максимальна при 100, безубыточность 89,98 и 110,02, но убыток не ограничен.

Бабочка лучше подходит под взгляд «97–103»: риск ограничен суммой 3,05.
