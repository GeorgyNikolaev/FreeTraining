# Паритет колл–пут и границы цен

Ещё до любой модели цены опционов связаны между собой и с ценой базового актива. Эти связи выводятся из одного отсутствия арбитража и не зависят от того, как будет двигаться цена. Урок выводит их и показывает, как ловить нарушения в котировках.

Всюду ниже опционы европейские, базовый актив без дивидендов, $r$ — непрерывная ставка, $\tau = T - t$. Про дивиденды — в конце.

## Паритет колл–пут

Колл и пут с одним страйком связаны жёстким равенством. Чтобы его увидеть, соберём два портфеля и сравним, что они принесут в экспирацию:
- **A**: купленный колл со страйком $K$ плюс облигация, которая в момент $T$ выплатит ровно $K$ (сегодня она стоит $Ke^{-r\tau}$);
- **B**: купленный пут с тем же страйком плюс одна акция.

| | Если $S_T \le K$ | Если $S_T > K$ |
|---|---|---|
| Портфель A | Колл не исполняем, остаётся облигация: $0 + K = K$ | Исполняем колл: $(S_T - K) + K = S_T$ |
| Портфель B | Продаём акцию по путу: $(K - S_T) + S_T = K$ | Пут не нужен, остаётся акция: $0 + S_T = S_T$ |

В обоих случаях портфели дают одно и то же. Значит, по закону одной цены (модуль 2) они и сегодня должны стоить одинаково: $C + Ke^{-r\tau} = P + S$. Перенесём слагаемые:

$$
C - P = S - Ke^{-r\tau},
$$

где $C$ и $P$ — сегодняшние цены колла и пута, $S$ — цена акции, $Ke^{-r\tau}$ — сегодняшняя стоимость страйка.

Справа стоит в точности стоимость форварда с ценой поставки $K$ (модуль 5). Отсюда словесная формулировка паритета: **купить колл и продать пут с одним страйком — то же самое, что заключить форвард**. Из этого равенства любой инструмент выражается через остальные:

| Синтетическая позиция | Из чего собрать |
|---|---|
| Купленный колл | Купленный пут + акция − облигация (займ $Ke^{-r\tau}$) |
| Купленный пут | Купленный колл − акция + облигация |
| Акция | Колл − пут + облигация |
| Длинный форвард | Колл − пут |

**Пример нарушения.** $S = 100$, $K = 100$, $r = 12\%$, $\tau = 0{,}5$. Рынок: колл 12, пут 4. По паритету $C - P$ должна быть $100 - 100e^{-0{,}06} = 5{,}82$, а на рынке 8. Колл дорог относительно пута. Продаём дорогое, покупаем дешёвое:

| Сегодня | Денежный поток |
|---|---|
| Продать колл | +12,00 |
| Купить пут | −4,00 |
| Купить акцию | −100,00 |
| Занять $100e^{-0{,}06}$ | +94,18 |
| **Итого** | **+2,18** |

В экспирацию при любой цене: акция уходит по 100 — либо её забирают по проданному коллу, либо мы продаём её по купленному путу — и эти 100 гасят займ. Прибыль 2,18 зафиксирована сегодня.

**Опционы на фьючерс** с ценой $F$: $C - P = (F - K)e^{-r\tau}$. Для **маржируемых** опционов Мосбиржи (предыдущий урок) премия не платится, и дисконтирования нет: $C - P = F - K$.

## Границы цен

Даже не зная будущей волатильности, можно сказать, в каком коридоре обязана лежать цена опциона. Все границы ниже доказываются одинаково: если цена вышла за границу, собирается портфель, который сегодня приносит деньги, а в будущем ничего не требует, — то есть арбитраж.

Обозначения: $C$ и $P$ — цены колла и пута со страйком $K$, $C(K_1)$ — цена колла со страйком $K_1$.

| Граница | Почему так |
|---|---|
| $C \ge \max(S - Ke^{-r\tau},\ 0)$ | Из паритета: $C = P + S - Ke^{-r\tau}$, а пут не может стоить меньше нуля |
| $C \le S$ | Колл даёт не больше, чем сама акция: право купить дешевле акции |
| $P \ge \max(Ke^{-r\tau} - S,\ 0)$ | Из паритета, где уже колл не меньше нуля |
| $P \le Ke^{-r\tau}$ | Максимум, что даст пут, — страйк $K$ (если акция обнулится); сегодня это $Ke^{-r\tau}$ |
| $C(K_1) \ge C(K_2)$ при $K_1 < K_2$ | Право купить дешевле не может стоить меньше права купить дороже |
| $C(K_1) - C(K_2) \le (K_2 - K_1)e^{-r\tau}$ | Разница выплат двух коллов не больше разницы страйков |
| $C(K)$ — выпуклая функция $K$ | См. ниже |

**Выпуклость по страйку** — самое неочевидное свойство. Возьмём три страйка $K_1 < K_2 < K_3$, где средний лежит между крайними: $K_2 = \lambda K_1 + (1-\lambda)K_3$ при некотором $\lambda$ от 0 до 1. Соберём портфель: купим $\lambda$ коллов со страйком $K_1$ и $(1-\lambda)$ коллов со страйком $K_3$, а один колл со страйком $K_2$ продадим. Проверив все возможные $S_T$, убеждаемся: выплата такого портфеля нигде не отрицательна (это ровно свойство выпуклости функции $(S_T - K)^+$ по $K$). Раз выплата неотрицательна, то и стоить портфель должен не меньше нуля:

$$
C(K_2) \le \lambda C(K_1) + (1-\lambda)C(K_3).
$$

Для равномерно расположенных страйков ($K_2$ ровно посередине, $\lambda = 1/2$) это записывается проще: $C(K_1) - 2C(K_2) + C(K_3) \ge 0$. Такой портфель называется бабочкой (следующий урок), и его отрицательная цена — верный признак арбитража. Для путов свойства те же, только цена пута по страйку **растёт**, а не убывает.

## Досрочное исполнение

**Американский колл на акцию без дивидендов не исполняют досрочно.** Это кажется странным: зачем ждать, если опцион уже глубоко в деньгах? Но цепочка неравенств показывает, что ждать выгоднее:

$$
C_{\text{амер}} \ge C_{\text{евр}} \ge S - Ke^{-r\tau} > S - K,
$$

где $C_{\text{амер}}$ и $C_{\text{евр}}$ — цены американского и европейского коллов. Первое неравенство — потому что у американского опциона прав больше. Второе — граница из таблицы выше. Третье верно, потому что при положительной ставке $Ke^{-r\tau} < K$.

Крайние части читаются так: опцион стоит строго больше, чем даст немедленное исполнение ($S - K$). Значит, вместо исполнения его выгоднее просто продать. Причины две: исполнив сейчас, мы раньше расстаёмся с деньгами на оплату страйка (теряем проценты) и лишаемся защиты на случай падения цены. Поэтому право на досрочное исполнение ничего не добавляет: $C_{\text{амер}} = C_{\text{евр}}$.

**Американский пут исполнять досрочно бывает выгодно.** Пусть акция почти обесценилась: $S = 1$, $K = 100$, $r = 12\%$, год до экспирации. Исполнив сейчас, получим 99 и разместим их: через год будет $99e^{0{,}12} = 111{,}6$. Ожидая, получим в экспирацию не больше 100. Пут глубоко в деньгах выгоднее исполнить, потому что его выплата ограничена $K$, а процент на $K$ теряется. Поэтому $P_{\text{амер}} > P_{\text{евр}}$, и для американского пута паритет превращается в неравенство:

$$
S - K \le C_{\text{амер}} - P_{\text{амер}} \le S - Ke^{-r\tau}.
$$

## Дивиденды

Если до экспирации ожидаются дивиденды с приведённой стоимостью $D$, держатель акции их получит, а держатель опциона — нет:

$$
C - P = S - D - Ke^{-r\tau}, \qquad \text{или} \qquad C - P = Se^{-q\tau} - Ke^{-r\tau}
$$

при непрерывной дивидендной доходности $q$. Американский колл на акцию с дивидендами иногда выгодно исполнить **накануне отсечки**: когда дивиденд больше потерянного процента на страйк и временной стоимости.

## Где ошибаются

- **Искать арбитраж по последним сделкам.** Колл мог торговаться час назад при другой цене акции. Проверять паритет можно только по одновременным котировкам, причём покупать по аску, а продавать по биду.
- **Забывать про стоимость займа акции.** Обратная сторона примера — продать акцию в шорт — требует платы за займ бумаг. Для «дефицитных» акций паритет систематически «нарушен» ровно на эту плату.
- **Применять паритет к американским опционам как равенство.** Для американских путов разница $C - P$ лежит в интервале. Равенство верно только для европейских.
- **Не учитывать дивиденды.** Кажущееся нарушение паритета перед отсечкой часто объясняется ожидаемым дивидендом, который рынок уже заложил в опционы.
