# Домашнее задание: сравнение ставок и поиск арбитража

Два расчёта на Python 3.12 с numpy 2.x, около 40 минут.

## Задача 1. Какое предложение выгоднее

Есть 1 млн рублей на год (365 дней). Четыре предложения:

| | Условия |
|---|---|
| A | Вклад 13,5% годовых с ежемесячной капитализацией |
| B | Вклад 14% годовых, простые проценты, выплата в конце срока, ACT/365F |
| C | Облигация с доходностью 13,8% годовых при полугодовом начислении |
| D | Размещение под 13,2% годовых, простые проценты, ACT/360 |

Результат: функция `to_continuous(...)`, которая переводит ставку с любым способом начисления и любой конвенцией в непрерывную, и таблица из четырёх строк с эффективной годовой и непрерывной ставкой. Предложения в таблице отсортированы по убыванию выгоды.

## Задача 2. Арбитраж в трёх состояниях

Через год рынок окажется в одном из трёх состояний. Торгуются четыре актива:

| Актив | Цена сегодня | Рост | Без изменений | Падение |
|---|---|---|---|---|
| Облигация | 0,95 | 1 | 1 | 1 |
| Акция | 100 | 120 | 100 | 85 |
| Актив C | 8 | 20 | 0 | 0 |
| Актив D | 6 | 0 | 0 | 15 |

Актив C платит $\max(S-100, 0)$, актив D — $\max(100-S, 0)$.

Результат:
1. Цены состояний, найденные по первым трём активам.
2. Безарбитражная цена актива D.
3. Конкретный арбитражный портфель: сколько единиц каждого актива купить или продать, сколько он приносит сегодня и чем докажете, что в каждом из трёх состояний его выплата равна нулю.

## Как проверить себя

**Задача 1.**
- Эффективные ставки: A — 14,367%, B — 14,000%, C — 14,276%, D — 13,383%. Порядок по выгоде: A, C, B, D.
- Непрерывные ставки: A — 13,425%, C — 13,345%, B — 13,103%, D — 12,560%.
- Если у B получилось не 14,000%, вы, скорее всего, применили сложное начисление к простой ставке.
- Если D оказалось выше 13,2%, но ниже 13,383%, вы посчитали срок как 360/365, а нужно 365/360: по ACT/360 в году 365 фактических дней, делённых на 360.

**Задача 2.**
- Цены состояний: $\psi = (0{,}40;\ 0{,}35;\ 0{,}20)$. Все положительны, значит, первые три актива между собой непротиворечивы.
- Безарбитражная цена D: $15 \cdot 0{,}20 = 3$. Рынок просит 6, актив D переоценён.
- Выплату D копирует портфель: +100 облигаций, −1 акция, +1 актив C. Проверка по состояниям: $100 - 120 + 20 = 0$, $100 - 100 + 0 = 0$, $100 - 85 + 0 = 15$. Стоимость копии: $95 - 100 + 8 = 3$.
- Арбитраж: продать D за 6, купить копию за 3. Сегодня +3, в будущем выплаты гасятся во всех состояниях.
- Типичная ошибка — решать `np.linalg.solve(D, payoff)` с матрицей, где строки — активы. Уравнение на количества — $D^\top\theta = X$, так что нужна транспонированная матрица.
