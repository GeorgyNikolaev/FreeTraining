# Шпаргалка

Обозначения: $S$ — цена актива, $K$ — страйк или цена поставки, $\tau$ — срок в годах, $r$ — непрерывная безрисковая ставка, $q$ — непрерывная доходность актива, $\sigma$ — годовая волатильность, $P(0,T)$ — дисконт-фактор, $N$ — функция нормального распределения, $\varphi$ — её плотность.

## Ставки и дисконтирование

| Что | Формула |
|---|---|
| Сложная → непрерывная | $r_c = m\ln(1 + r_m/m)$ |
| Непрерывная → сложная | $r_m = m(e^{r_c/m} - 1)$ |
| Эффективная годовая | $(1 + r_m/m)^m - 1$ |
| Дисконт-фактор | $P(0,T) = e^{-r_cT} = (1 + r_1)^{-T}$ |
| Приведённая стоимость | $PV = \sum_i c_i P(0,T_i)$ |
| Аннуитет | $PV = c\,\dfrac{1 - (1+i)^{-n}}{i}$ |
| Форвардная ставка (простая) | $f(T_1,T_2) = \dfrac{1}{T_2 - T_1}\left(\dfrac{P(0,T_1)}{P(0,T_2)} - 1\right)$ |
| Капитализация ставки овернайт за период | $\left[\prod(1 + r_id_i/B) - 1\right]\cdot B/D$ |

| Конвенция | Где (сентябрь 2026) |
|---|---|
| ACT/365F | RUB, RUONIA, GBP, SONIA |
| ACT/360 | USD, EUR: SOFR, €STR, плавающие ноги |
| 30/360 | Фиксированные ноги USD-свопов, корпоративные облигации США |
| ACT/ACT | US Treasuries, еврооблигации |

**Отсутствие арбитража:** одинаковые выплаты → одинаковая цена. Арбитража нет ⇔ существуют цены состояний $\psi > 0$ с $p = D\psi$. Цена = $P(0,T)\cdot\mathbb{E}^{\mathbb{Q}}[\text{выплата}]$.

## Акции

| Что | Формула |
|---|---|
| Лог-доходность | $r_t = \ln(S_t/S_{t-1})$, складывается по времени |
| Годовая волатильность | $\sigma_{\text{день}}\sqrt{252}$, $\sigma_{\text{мес}}\sqrt{12}$ |
| Медиана и среднее при ГБД | $S_0e^{(\mu - \sigma^2/2)T}$ и $S_0e^{\mu T}$ |
| Коэффициент корректировки на дивиденд | $(S^- - D)/S^-$ ко всем ценам до отсечки |
| Дисперсия портфеля | $w^\top\Sigma w$ |
| Бета | $\beta = \rho\,\sigma_i/\sigma_M$ |
| Доходность с плечом $k$ | $kR - (k-1)b$ |
| Маржин-колл, длинная позиция | $S^* = L/(n(1 - m))$ |
| Маржин-колл, короткая позиция | $S^* = C/(n(1 + m))$ |
| Фонд с плечом $L$ | $\ln(V_T/V_0) = L\ln(S_T/S_0) - (L^2 - L)\sigma^2T/2$ |

## Облигации и денежный рынок

| Что | Формула |
|---|---|
| НКД | $C\cdot(t - t_0)/(t_1 - t_0)$; грязная = чистая + НКД |
| Бутстрэппинг | $P(0,T_n) = \big(P_{\text{грязн}} - \sum_{i<n}c_iP(0,T_i)\big)/c_n$ |
| Дюрация Маколея | $D = \frac{1}{P}\sum t_i\,PV_i$ |
| Модифицированная дюрация | $D_{\text{mod}} = D/(1 + y/m)$ |
| DV01 | $D_{\text{mod}}\cdot P\cdot 0{,}0001$; складывается по позициям |
| Выпуклость (годовой купон) | $C = \frac{1}{P}\sum t_i(t_i+1)c_i/(1+y)^{t_i+2}$ |
| Изменение цены | $\Delta P/P \approx -D_{\text{mod}}\Delta y + \tfrac{1}{2}C(\Delta y)^2$ |
| Хедж по DV01 | $N_h = N\cdot\text{DV01}/\text{DV01}_h$ |
| Кредитный треугольник | $s \approx \lambda(1 - R)$; $Q(T) = e^{-\lambda T}$ |
| Вероятность дефолта из цены | $p = (1 - P_{\text{корп}}/P_{\text{гос}})/(1 - R)$ |
| Выкуп по РЕПО | $\text{сумма}\cdot(1 + r\cdot d/365)$, выдают стоимость залога × (1 − дисконт) |

Флоатер без спреда в дату пересмотра купона стоит номинал. Иммунизация: равны PV и дюрации активов и обязательств, выпуклость активов больше.

## Форварды и фьючерсы

| Базовый актив | Форвардная цена |
|---|---|
| Без дохода | $Se^{r\tau}$ |
| Известный доход с PV $I$ | $(S - I)e^{r\tau}$ |
| Доходность $q$ | $Se^{(r-q)\tau}$ |
| Валюта | $Se^{(r_d - r_f)\tau}$ или $S(1 + r_d\tau_d)/(1 + r_f\tau_f)$ |
| Товар | $Se^{(r + u - y)\tau}$ |

| Что | Формула |
|---|---|
| Стоимость действующего форварда | $(F_t - K)e^{-r(T-t)}$ |
| Вариационная маржа | $N\cdot(F_t - F_{t-1})\cdot\text{стоимость пункта}$ |
| Эффективная цена хеджа | $F_1 + b_2$, где $b_2 = S_2 - F_2$ |
| Хедж с минимальной дисперсией | $h^* = \rho\,\sigma_S/\sigma_F$, $N^* = h^*Q_A/Q_F$ |
| Изменение беты портфеля | $N = (\beta - \beta^*)\,V/(F\cdot m)$, плюс — продать |
| Фандинг вечного фьючерса | $\approx S(r_d - r_f)/365$ в день; платят лонги, если цена выше спота |

## Свопы

| Что | Формула |
|---|---|
| Аннуитет | $A = \sum\tau_iP(0,T_i)$ |
| Справедливая ставка (одна кривая) | $S = (1 - P(0,T_n))/A$ |
| Стоимость для плательщика фиксированной ставки | $N(1 - P(0,T_n) - KA) = N(S - K)A$ |
| Через форварды | $N\sum\tau_i(F_i - K)P(0,T_i)$ |
| DV01 свопа | $\approx N\cdot A\cdot 0{,}0001$ |
| Бутстрэппинг OIS | $P_n = (1 - S_n\sum_{i<n}\tau_iP_i)/(1 + S_n\tau_n)$ |
| Мультикривая оценка | $N\sum\tau_i(F^I_i - K)P^{\text{OIS}}(0,T_i)$ |
| Кросс-валютный своп | $V = S_t B_{\text{иностр}} - B_{\text{внутр}}$ |
| CVA | $(1 - R)\sum EE(t_i)[Q(t_{i-1}) - Q(t_i)]P(0,t_i)$ |

Порядок построения кривых: сначала OIS (дисконтирование), потом кривые индексов. Плательщик фиксированной ставки выигрывает при росте ставок.

## Опционы: выплаты, паритет, границы

| Позиция | Выплата |
|---|---|
| Колл / пут | $(S_T - K)^+$ / $(K - S_T)^+$ |
| Паритет (европейские, без дивидендов) | $C - P = S - Ke^{-r\tau}$ |
| С дивидендами | $C - P = Se^{-q\tau} - Ke^{-r\tau}$ |
| На фьючерс / маржируемый | $C - P = (F - K)e^{-r\tau}$ / $F - K$ |
| Границы колла | $\max(S - Ke^{-r\tau}, 0) \le C \le S$ |
| Границы пута | $\max(Ke^{-r\tau} - S, 0) \le P \le Ke^{-r\tau}$ |
| Спред страйков | $0 \le C(K_1) - C(K_2) \le (K_2 - K_1)e^{-r\tau}$ |
| Выпуклость | $C(K_1) - 2C(K_2) + C(K_3) \ge 0$ при равном шаге |

Американский колл без дивидендов = европейский. Американский пут глубоко в деньгах бывает выгодно исполнить досрочно.

| Взгляд | Стратегия |
|---|---|
| Рост до уровня | Бычий колл-спред |
| Падение до уровня | Медвежий пут-спред |
| Сильное движение, направление неизвестно | Купленный стрэддл или стрэнгл |
| Цена стоит | Бабочка (риск ограничен) или проданный стрэддл (риск не ограничен) |
| Защитить акции | Защитный пут; бесплатно — коллар |
| Доход с акций при боковике | Покрытый колл (= проданный пут + облигация) |

## Оценка опционов

| Что | Формула |
|---|---|
| Одношаговая модель | $V = e^{-r\Delta t}[qV_u + (1-q)V_d]$, $q = (e^{r\Delta t} - d)/(u - d)$ |
| Дельта шага | $\Delta = (V_u - V_d)/(S(u - d))$ |
| CRR | $u = e^{\sigma\sqrt{\Delta t}}$, $d = 1/u$, вероятность $(e^{(r-\delta)\Delta t} - d)/(u - d)$, $\delta$ — доходность актива |
| Лемма Ито | $df = (f_t + \mu Sf_S + \tfrac{1}{2}\sigma^2S^2f_{SS})dt + \sigma Sf_S\,dW$ |
| ГБД | $S_T = S_0\exp[(\mu - \sigma^2/2)T + \sigma W_T]$ |
| Уравнение Блэка–Шоулза | $V_t + rSV_S + \tfrac{1}{2}\sigma^2S^2V_{SS} - rV = 0$ |
| $d_1$, $d_2$ | $d_1 = \dfrac{\ln(S/K) + (r - q + \sigma^2/2)\tau}{\sigma\sqrt\tau}$, $d_2 = d_1 - \sigma\sqrt\tau$ |
| Колл | $Se^{-q\tau}N(d_1) - Ke^{-r\tau}N(d_2)$ |
| Пут | $Ke^{-r\tau}N(-d_2) - Se^{-q\tau}N(-d_1)$ |
| Блэк (фьючерс) | $e^{-r\tau}[FN(d_1) - KN(d_2)]$, $d_1 = \dfrac{\ln(F/K) + \sigma^2\tau/2}{\sigma\sqrt\tau}$; маржируемый — без $e^{-r\tau}$ |
| Гарман–Кольхаген | $q = r_f$, $r = r_d$ |
| Цифровой колл | $e^{-r\tau}N(d_2)$ |
| Башелье | $(F - K)N(d) + \sigma_N\sqrt{T}\varphi(d)$, $d = (F - K)/(\sigma_N\sqrt{T})$ |

Ставка в формулах непрерывная: 14% эффективных = $\ln 1{,}14 = 13{,}1\%$.

## Греки (без дивидендов)

| Грек | Колл | Пут | Рыночные единицы |
|---|---|---|---|
| $\Delta$ | $N(d_1)$ | $N(d_1) - 1$ | |
| $\Gamma$ | $\varphi(d_1)/(S\sigma\sqrt\tau)$ | так же | |
| $\nu$ | $S\varphi(d_1)\sqrt\tau$ | так же | ÷100 → на 1 п.п. |
| $\Theta$ | $-\dfrac{S\varphi(d_1)\sigma}{2\sqrt\tau} - rKe^{-r\tau}N(d_2)$ | $-\dfrac{S\varphi(d_1)\sigma}{2\sqrt\tau} + rKe^{-r\tau}N(-d_2)$ | ÷365 → на день |
| $\rho$ | $K\tau e^{-r\tau}N(d_2)$ | $-K\tau e^{-r\tau}N(-d_2)$ | ÷100 → на 1 п.п. |

| Правило | Формула |
|---|---|
| Разложение P&L | $\delta V \approx \Delta\delta S + \tfrac{1}{2}\Gamma\delta S^2 + \Theta\delta t + \nu\delta\sigma$ |
| Тета и гамма (дельта-нейтрально) | $\Theta \approx -\tfrac{1}{2}\sigma^2S^2\Gamma$ |
| P&L продавца с дельта-хеджем | $\approx \tfrac{1}{2}\int\Gamma S^2(\sigma_i^2 - \sigma_r^2)dt \approx \nu(\sigma_i - \sigma_r)$ |
| Ошибка дискретного хеджа | $\approx\sqrt{\pi/4}\,\nu\sigma/\sqrt{N}$ |
| Стрэддл на деньгах | $\approx 0{,}8\,S\sigma\sqrt\tau$ |
| Подразумеваемая волатильность (Ньютон) | $\sigma_{n+1} = \sigma_n - (\text{BS}(\sigma_n) - C)/\nu$ |
| Плотность из цен | $q(K) = e^{r\tau}\partial^2C/\partial K^2$ |
| Риск-реверсал / баттерфляй | $\sigma_{25C} - \sigma_{25P}$ / $\tfrac{1}{2}(\sigma_{25C} + \sigma_{25P}) - \sigma_{\text{ATM}}$ |

Гамма и вега максимальны около страйка. Гамма растёт к экспирации, вега падает.

## Экзотика, кредит, ставки, структурные продукты

| Что | Формула или правило |
|---|---|
| Барьерный паритет | knock-in + knock-out = обычный опцион |
| Дискретный барьер | $B' = Be^{\mp 0{,}5826\sigma\sqrt{\Delta t}}$ (сдвиг от цены) |
| Ошибка Монте-Карло | $\hat s/\sqrt{n}$ |
| Контрольная переменная | $X - b(Y - \mathbb{E}Y)$, $b = \text{Cov}(X,Y)/\text{Var}\,Y$, дисперсия ×$(1 - \rho^2)$ |
| RPV01 CDS | $\sum\tau_iP_i[Q_i + \tfrac{1}{2}(Q_{i-1} - Q_i)]$ |
| Защитная нога CDS | $(1 - R)\sum P_i(Q_{i-1} - Q_i)$ |
| Аванс CDS | $(s^* - c)\cdot\text{RPV01}$, купоны 100 или 500 б.п. |
| Мертон | капитал = колл на активы, $PD = N(-d_2)$ |
| Убыток транша $[A, D]$ | $[(L - A)^+ - (L - D)^+]/(D - A)$ |
| Кэплет (Блэк) | $N\tau P(0,T_{i+1})[FN(d_1) - KN(d_2)]$, волатильность до $T_i$ |
| Payer-свопцион | $N\cdot A(0)\cdot\text{Black или Bachelier}(S_0, K)$ |
| Паритет кэп–флор | кэп − флор = своп плательщика фиксированной ставки |

| Продукт | Разложение |
|---|---|
| Защита капитала | Бескупонная облигация + $k$ коллов; участие $k$ = (100 − облигация − маржа)/колл |
| Обратная конвертируемая облигация | Облигация с купоном − пут |
| Автоколл | Облигация + условные цифровые опционы − пут down-and-in; Монте-Карло |
| Конвертируемая облигация | Облигация + колл на акции эмитента |
| Облигация с call-офертой | Облигация − receiver-свопцион |

Порядок разбора продукта: выплаты по сценариям → облигационная часть → опционы → оценка (формула или Монте-Карло) → кредитный спред эмитента → сравнение с ценой размещения.

## Типовые ловушки

| Ловушка | Проверка |
|---|---|
| Смешаны конвенции ставок | Обе ставки в одной базе и с одним начислением? |
| Формула дала грязную цену, сравниваю с чистой | Вычтен НКД? |
| Хедж по номиналу | Хедж по DV01, бете или $h^*$? |
| Своп дисконтирован по индексу | Дисконтирование по OIS для обеспеченных сделок? |
| Цена опциона вне денег по IV на деньгах | IV своего страйка? |
| Вега, тета в «сырых» единицах | На 1 п.п. и на день? |
| Монте-Карло без интервала | Указан ли ±1,96·ошибка? |
| Защита капитала «гарантирована» | Кто эмитент и каков его кредитный риск? |
