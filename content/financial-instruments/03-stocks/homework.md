# Домашнее задание: риск портфеля из двух акций

Расчёт на Python 3.12 с numpy 2.x, около 45 минут. Данные учебные, но устроены как настоящие: у одной акции в середине периода прошла дивидендная отсечка.

## Исходные данные

Месячные цены закрытия за 13 месяцев. Дивиденд акции A — 25 рублей, отсечка между месяцами 6 и 7 (нумерация с нуля).

```python
import numpy as np

A = np.array([250, 262, 255, 270, 281, 276, 290, 262, 268, 284, 291, 300, 309.0])
B = np.array([150, 153, 151, 157, 161, 159, 165, 162, 164, 170, 172, 175, 178.0])
index = np.array([3000, 3075, 3030, 3150, 3220, 3190, 3300, 3240, 3265, 3370, 3420, 3460, 3520.0])
div_A = np.zeros(13)
div_A[7] = 25.0
```

## Что получить

1. Ряд цен A, скорректированный на дивиденд методом коэффициентов из урока про акции, и полная доходность A за период. Сравните её с доходностью по сырым ценам.
2. Годовую волатильность (по месячным лог-доходностям) для A, B и индекса. Для A посчитайте её дважды: по сырым и по скорректированным ценам.
3. Беты A и B к индексу — тоже для A в двух вариантах.
4. Годовую волатильность портфеля 60% A и 40% B двумя способами: через $w^\top\Sigma w$ и напрямую по ряду доходностей портфеля с ежемесячной ребалансировкой.
5. Инвестор купил 3000 акций A по 309 рублей: половину на свои деньги, половину в долг у брокера. Поддерживающий уровень маржи 25%. При какой цене придёт маржин-колл и какому месячному падению это соответствует? Встречалось ли такое падение в истории A?

Итог — короткий вывод на 3–4 предложения: насколько ошибка с дивидендами искажает риск и что это значит для маржинальной позиции.

## Как проверить себя

| Показатель | Ожидаемое значение |
|---|---|
| Скорректированная цена A в месяце 0 | 228,45 (коэффициент $265/290$) |
| Полная доходность A | 35,26% против 23,60% по сырым ценам |
| Волатильность A: скорректированная / сырая | 10,11% / 15,98% |
| Волатильность B / индекса | 6,85% / 6,58% |
| Бета A: скорректированная / сырая | 1,49 / 2,21 |
| Бета B | 1,03 |
| Волатильность портфеля 60/40 | 8,75% обоими способами (расхождение в четвёртом знаке) |
| Цена маржин-колла | $463\,500/(3000 \cdot 0{,}75) = 206$, падение на 33,3% |

Признаки ошибок:
- **Волатильность A около 16%.** Использованы сырые цены: дивидендный гэп −9,7% засчитан как рыночное движение.
- **Волатильность около 2,9%.** Не сделан годовой пересчёт через $\sqrt{12}$.
- **Способы из пункта 4 расходятся в первом знаке.** Для ковариаций взяты сырые цены A, а для ряда портфеля — скорректированные, или наоборот.
- **Цена маржин-колла 231,75.** Посчитано $S_0(1-m)$, то есть потеря 25% стоимости позиции. Правильно — момент, когда собственные средства составляют 25% позиции.

В истории A нет месячного падения больше 10%, если считать по скорректированным ценам. По сырым ценам есть −9,7%, и это ложный сигнал риска. Но и без реальных провалов 12 месяцев данных — слишком мало, чтобы судить о хвостах. Для маржинальной позиции важен риск редкого сильного падения, а не типичная волатильность.
