# Экзотические опционы и метод Монте-Карло

Экзотическим называют любой опцион с выплатой сложнее $(S_T - K)^+$: зависящей от пути цены, от нескольких активов или разрывной. Для немногих есть формулы, для остальных цену считают моделированием. Урок разбирает главные виды экзотики и метод Монте-Карло с приёмами, без которых он слишком медленный.

Параметры примеров: $S = K = 100$, $r = 12\%$, $\sigma = 25\%$, $T = 0{,}25$. Обычный колл стоит 6,528.

## Виды экзотических опционов

| Вид | Выплата | Зачем | Формула в модели Блэка–Шоулза |
|---|---|---|---|
| Барьерный: knock-out | Обычная, если цена **не** касалась барьера $B$ за срок | Дешевле обычного опциона | Есть (непрерывное наблюдение) |
| Барьерный: knock-in | Обычная, **только если** цена касалась барьера | Дешёвая защита от сильного движения | Есть |
| Азиатский | $(\bar S - K)^+$, где $\bar S$ — среднее за период | Хедж закупок по средней цене (товарные свопы, модуль 6); трудно манипулировать | Для геометрического среднего — есть, для арифметического — нет |
| Бинарный (цифровой) | Фиксированная сумма, если $S_T > K$ | Ставка «да или нет»; строительный блок структурных продуктов | $e^{-r\tau}N(d_2)$ на единицу выплаты |
| Lookback | $S_{\max} - S_T$ или $S_T - S_{\min}$ | «Купить по минимуму» | Есть, но опцион очень дорогой |
| Корзинный | $(\sum w_i S_i - K)^+$ | Экспозиция на несколько активов дешевле, чем опционы на каждый | Нет, зависит от корреляций |
| Кванто | Выплата по иностранному активу, пересчитанная по фиксированному курсу | Инвестор не хочет валютного риска | Есть, с поправкой на корреляцию актива и курса |

### Барьерные опционы

**Паритет входа и выхода:** knock-in + knock-out с одним барьером = обычный опцион, потому что ровно один из них сработает. Колл «down-and-out» (исчезает, если цена опустилась до 90) по формуле Райнера–Рубинштейна стоит 6,256. Значит, «down-and-in» стоит $6{,}528 - 6{,}256 = 0{,}272$.

Барьер 90 почти не удешевил колл: сценарии, где цена сначала падает на 10%, а потом к экспирации поднимается выше 100, редки и мало весят в цене колла.

**Риск хеджа у барьера.** Если цена около барьера, а опцион в деньгах, стоимость knock-out опциона разрывна: чуть ниже барьера она обнуляется. Дельта и гамма огромны, хедж нестабилен. Для продавца это главный практический риск барьерных опционов.

### Бинарный опцион

Цифровой колл «платит 1, если $S_T > 100$» стоит $e^{-r\tau}N(d_2) = 0{,}5536$. На практике его хеджируют **колл-спредом**: $(C(99) - C(101))/2 = 0{,}5536$. У экспирации около страйка дельта цифрового опциона бесконечна (**пин-риск**), поэтому продавец консервативно оценивает его как спред со сдвигом страйков в свою пользу.

## Метод Монте-Карло

Из модуля 8 известно: цена дериватива — это дисконтированное среднее его выплаты по риск-нейтральной мере, $e^{-rT}\mathbb{E}^{\mathbb{Q}}[\text{выплата}]$. Когда формулы для этого среднего нет, его считают перебором: разыгрывают много случайных сценариев будущего и усредняют. Это и есть **метод Монте-Карло**.

Алгоритм:

1. Сгенерировать $n$ траекторий цены под мерой $\mathbb{Q}$ по шагам: $S_{t+\Delta t} = S_t\exp\big[(r - \sigma^2/2)\Delta t + \sigma\sqrt{\Delta t}\,Z\big]$, где $Z$ — случайная величина из стандартного нормального распределения, своя на каждом шаге. Это точное решение ГБД из модуля 8, поэтому шаг можно брать любой, лишь бы он совпадал с датами наблюдений в договоре.
2. Для каждой траектории посчитать выплату опциона по его условиям.
3. Усреднить выплаты и дисконтировать: это и есть оценка цены.
4. Оценить погрешность: стандартная ошибка равна $\hat s/\sqrt{n}$, где $\hat s$ — выборочное стандартное отклонение выплат, а $n$ — число сценариев.

Ключевое свойство: ошибка убывает как $1/\sqrt{n}$ **независимо от числа переменных**. У дерева или сетки сложность растёт экспоненциально с числом базовых активов, а у Монте-Карло — нет. Поэтому для корзин из десяти акций или для выплат, зависящих от всего пути цены, это единственный рабочий метод.

### Дискретное наблюдение барьера

Барьер, наблюдаемый раз в день, пересекается реже, чем непрерывный: цена может «проскочить» ниже барьера между наблюдениями. Опцион knock-out с дневным наблюдением дороже непрерывного.

| Метод | Down-and-out колл, $B = 90$ |
|---|---|
| Формула, непрерывный барьер | 6,256 |
| Монте-Карло, 63 дневных наблюдения, 800 000 сценариев | 6,346 ± 0,019 |
| Формула с поправкой Броуди–Глассермана–Коу: $B' = Be^{-0{,}5826\,\sigma\sqrt{\Delta t}} = 89{,}18$ | 6,341 |

Поправка сдвигает барьер от цены на $0{,}5826\,\sigma\sqrt{\Delta t}$ в логарифмах и позволяет пользоваться непрерывной формулой для дискретного барьера. Если моделировать барьер Монте-Карло с шагом крупнее частоты наблюдений в договоре, цена будет систематически неверной.

### Снижение дисперсии

Ошибка падает как $1/\sqrt{n}$, поэтому «в лоб» точность даётся дорого: чтобы уменьшить погрешность в 10 раз, нужно в 100 раз больше сценариев. Дешевле уменьшить не количество, а разброс.

- **Антитетические сценарии.** Каждый разыгранный $Z$ используем дважды: как есть и со знаком минус. Получается пара зеркальных траекторий — если одна ушла вверх, другая ушла вниз ровно так же. Их результаты усредняются, случайный перекос выборки частично гасится (домашнее задание модуля 8).
- **Контрольная переменная.** Допустим, рядом с нашей выплатой $X$ есть похожая величина $Y$, для которой точная цена $\mathbb{E}Y$ известна по формуле. Тогда по той же выборке считаем и $Y$, смотрим, насколько Монте-Карло промахнулся по ней, и на ту же величину правим оценку $X$:

$$
X_{\text{испр}} = X - b\,(Y - \mathbb{E}Y), \qquad b = \frac{\operatorname{Cov}(X,Y)}{\operatorname{Var}(Y)},
$$

  где $b$ — коэффициент, подобранный так, чтобы убрать как можно больше шума. Дисперсия падает в $1/(1 - \rho^2_{XY})$ раз, где $\rho_{XY}$ — корреляция между $X$ и $Y$: при корреляции 0,999 это выигрыш в сотни раз.

**Пример: азиатский колл** на арифметическое среднее 63 дневных цен. Контрольная переменная — геометрический азиатский колл, для которого есть формула (3,5791). Корреляция выплат почти 1.

| Оценка, 100 000 сценариев | Цена | 95%-й интервал |
|---|---|---|
| Простая | 3,6906 | ± 0,0307 |
| С контрольной переменной ($b = 1{,}021$) | 3,6631 | ± 0,0005 |

Дисперсия упала примерно в 3500 раз. Без контрольной переменной для той же точности понадобилось бы около 350 миллионов сценариев.

```python
# Python 3.12, numpy 2.x, scipy 1.13+
import numpy as np
from math import exp, log, sqrt
from scipy.stats import norm

S, K, r, s, T, m, n = 100.0, 100.0, 0.12, 0.25, 0.25, 63, 100_000
dt = T / m
rng = np.random.default_rng(11)
Z = rng.standard_normal((n, m))
paths = np.exp(log(S) + np.cumsum((r - s * s / 2) * dt + s * sqrt(dt) * Z, axis=1))

disc = exp(-r * T)
X = disc * np.maximum(paths.mean(axis=1) - K, 0)                 # арифметический азиатский
Y = disc * np.maximum(np.exp(np.log(paths).mean(axis=1)) - K, 0)  # геометрический азиатский

# Точная цена геометрического азиатского опциона с дискретным усреднением
t = dt * np.arange(1, m + 1)
mu_g = log(S) + (r - s * s / 2) * t.mean()
var_g = s * s * np.minimum.outer(t, t).mean()
d1 = (mu_g - log(K) + var_g) / sqrt(var_g)
EY = disc * (exp(mu_g + var_g / 2) * norm.cdf(d1) - K * norm.cdf(d1 - sqrt(var_g)))

b = np.cov(X, Y)[0, 1] / Y.var(ddof=1)
cv = X - b * (Y - EY)
print(round(EY, 4), round(X.mean(), 4), round(cv.mean(), 4), round(1.96 * cv.std() / sqrt(n), 4))
# 3.5791 3.6906 3.6631 0.0005
```

## Где ошибаются

- **Моделировать дискретный барьер крупным шагом.** Барьер с дневным наблюдением, проверяемый раз в неделю, даёт цену knock-out опциона выше правильной, потому что пропущены касания.
- **Оценивать экзотику одной волатильностью.** Цена барьерного опциона зависит от улыбки у барьера сильнее, чем цена обычного. Модель с единой $\sigma$ может ошибаться на десятки процентов. Для экзотики нужны модели, откалиброванные к поверхности (модуль 9).
- **Не указывать погрешность Монте-Карло.** Цена без доверительного интервала — непроверяемое число. Разница двух оценок, не превышающая сумму погрешностей, ничего не значит.
- **Считать греки конечными разностями на разных сценариях.** Цены при $S$ и $S + h$ нужно считать на **одних и тех же** случайных числах. Иначе шум разности на порядки больше самой греки.
