# Модель Блэка–Шоулза

Урок соединяет всё, что было в модуле. Идея дельта-хеджа из биномиальной модели в непрерывном времени с леммой Ито даёт уравнение в частных производных. Его решение — формула Блэка–Шоулза. Второй путь к той же формуле — риск-нейтральное матожидание. В конце — варианты формулы для фьючерсов и валют.

## Допущения

1. Цена акции следует геометрическому броуновскому движению $dS = \mu S\,dt + \sigma S\,dW$ с постоянной $\sigma$.
2. Безрисковая ставка $r$ постоянна.
3. Торговля непрерывна, без издержек и налогов, разрешены короткие продажи и дробные количества.
4. Дивидендов нет (обобщение ниже).
5. Арбитража нет.

## Вывод уравнения через дельта-хедж

Пусть $V(S, t)$ — цена опциона. По лемме Ито (предыдущий урок):

$$
dV = \left(V_t + \mu S V_S + \tfrac{1}{2}\sigma^2S^2V_{SS}\right)dt + \sigma S V_S\,dW.
$$

Составим портфель: продан один опцион, куплено $\Delta = V_S$ акций. Его стоимость $\Pi = -V + V_S\,S$. За время $dt$, при неизменном $\Delta$:

$$
d\Pi = -dV + V_S\,dS = -\left(V_t + \tfrac{1}{2}\sigma^2S^2V_{SS}\right)dt.
$$

Члены с $dW$ сократились: портфель **мгновенно безрисков**. Сократился и снос $\mu$. Безрисковый портфель должен приносить безрисковую ставку, $d\Pi = r\Pi\,dt$, иначе есть арбитраж. Приравниваем:

$$
\boxed{\;V_t + rSV_S + \tfrac{1}{2}\sigma^2S^2V_{SS} - rV = 0\;}
$$

Это **уравнение Блэка–Шоулза**. Опционы разных видов — разные граничные условия: для европейского колла $V(S, T) = (S - K)^+$.

Реальный снос $\mu$ в уравнение не входит. Цена опциона зависит от волатильности, но не от ожидаемой доходности акции — так же, как в биномиальной модели она не зависела от $p$.

## Риск-нейтральная оценка

Уравнение линейное параболическое. По **теореме Фейнмана–Каца** его решение — матожидание:

$$
V(S, t) = e^{-r\tau}\,\mathbb{E}^{\mathbb{Q}}\big[\text{выплата}(S_T)\,\big|\,S_t = S\big],
$$

где под мерой $\mathbb{Q}$ цена растёт с безрисковой ставкой: $dS = rS\,dt + \sigma S\,dW^{\mathbb{Q}}$.

Связь с реальной мерой даёт **теорема Гирсанова**. Процесс $W^{\mathbb{Q}}_t = W_t + \lambda t$, где $\lambda = (\mu - r)/\sigma$, — броуновское движение относительно меры $\mathbb{Q}$ с плотностью

$$
\frac{d\mathbb{Q}}{d\mathbb{P}} = \exp\!\left(-\lambda W_T - \tfrac{1}{2}\lambda^2 T\right).
$$

Подставив $dW = dW^{\mathbb{Q}} - \lambda\,dt$, получаем $dS = rS\,dt + \sigma S\,dW^{\mathbb{Q}}$. Величина $\lambda$ называется **рыночной ценой риска**: смена меры убирает премию за риск из сноса, а волатильность не трогает. Это непрерывный аналог перехода от $p$ к $q$.

## Формула

Под $\mathbb{Q}$: $\ln S_T = \ln S + (r - \sigma^2/2)\tau + \sigma\sqrt{\tau}\,Z$, где $Z \sim \mathcal{N}(0,1)$. Выплата колла положительна, когда $S_T > K$, то есть когда $Z > -d_2$, где

$$
d_2 = \frac{\ln(S/K) + (r - \sigma^2/2)\tau}{\sigma\sqrt{\tau}}, \qquad d_1 = d_2 + \sigma\sqrt{\tau}.
$$

Тогда:
- $\mathbb{Q}(S_T > K) = N(d_2)$;
- $\mathbb{E}^{\mathbb{Q}}[S_T\,\mathbf{1}_{S_T > K}] = Se^{r\tau}N(d_1)$. Выделяем полный квадрат в показателе: $e^{\sigma\sqrt{\tau}z}\varphi(z) = e^{\sigma^2\tau/2}\varphi(z - \sigma\sqrt{\tau})$, и интегрирование от $-d_2$ даёт $N(d_2 + \sigma\sqrt{\tau})$.

Итог — **формула Блэка–Шоулза**:

$$
C = S\,N(d_1) - Ke^{-r\tau}N(d_2), \qquad P = Ke^{-r\tau}N(-d_2) - S\,N(-d_1).
$$

Пут получается из паритета колл–пут (модуль 7).

**Смысл слагаемых.** $N(d_2)$ — риск-нейтральная вероятность исполнения. $N(d_1)$ — дельта колла: число акций в реплицирующем портфеле. Колл — это купленные $N(d_1)$ акций и займ $Ke^{-r\tau}N(d_2)$.

**Пример.** $S = 100$, $K = 100$, $r = 12\%$, $\sigma = 25\%$, $\tau = 0{,}25$.

| Величина | Значение |
|---|---|
| $d_1$ | $(0 + (0{,}12 + 0{,}03125)\cdot 0{,}25)/(0{,}25\cdot 0{,}5) = 0{,}3025$ |
| $d_2$ | $0{,}3025 - 0{,}125 = 0{,}1775$ |
| $N(d_1)$, $N(d_2)$ | 0,6189; 0,5704 |
| Колл | $61{,}886 - 97{,}045\cdot 0{,}5704 = 6{,}528$ |
| Пут | $6{,}528 - 100 + 97{,}045 = 3{,}573$ |

Это те самые котировки, на которых строились стратегии в модуле 7, и предел, к которому сходилось дерево.

## Варианты для других базовых активов

| Базовый актив | Формула колла | $d_1$ |
|---|---|---|
| Акция с дивидендной доходностью $q$ (Мертон) | $Se^{-q\tau}N(d_1) - Ke^{-r\tau}N(d_2)$ | $\dfrac{\ln(S/K) + (r - q + \sigma^2/2)\tau}{\sigma\sqrt{\tau}}$ |
| Валюта (Гарман–Кольхаген) | $Se^{-r_f\tau}N(d_1) - Ke^{-r_d\tau}N(d_2)$ | $\dfrac{\ln(S/K) + (r_d - r_f + \sigma^2/2)\tau}{\sigma\sqrt{\tau}}$ |
| Фьючерс (Блэк, 1976) | $e^{-r\tau}\big[F\,N(d_1) - K\,N(d_2)\big]$ | $\dfrac{\ln(F/K) + \sigma^2\tau/2}{\sigma\sqrt{\tau}}$ |

Во всех случаях $d_2 = d_1 - \sigma\sqrt{\tau}$. Все три — одна формула. Подставьте форвардную цену $F = Se^{(r - q)\tau}$ в формулу Блэка, и получится формула Мертона.

**Маржируемые опционы на фьючерсы** (модуль 7) не требуют уплаты премии, поэтому множитель $e^{-r\tau}$ пропадает: $C = F\,N(d_1) - K\,N(d_2)$. Опцион колл на Si со страйком 85 000 при $F = 84\,000$, $\sigma = 15\%$ и 30 днях до экспирации стоит 1004 пункта. Если бы премию платили сразу, при ставке 14% цена была бы 993.

```python
# Python 3.12, scipy 1.13+
from math import exp, log, sqrt
from scipy.stats import norm

def black_scholes(S, K, r, sigma, tau, kind="call", q=0.0):
    d1 = (log(S / K) + (r - q + 0.5 * sigma**2) * tau) / (sigma * sqrt(tau))
    d2 = d1 - sigma * sqrt(tau)
    if kind == "call":
        return S * exp(-q * tau) * norm.cdf(d1) - K * exp(-r * tau) * norm.cdf(d2)
    return K * exp(-r * tau) * norm.cdf(-d2) - S * exp(-q * tau) * norm.cdf(-d1)

def black76(F, K, r, sigma, tau, kind="call", margined=False):
    df = 1.0 if margined else exp(-r * tau)
    return df * black_scholes(F, K, 0.0, sigma, tau, kind)

print(round(black_scholes(100, 100, 0.12, 0.25, 0.25), 3))               # 6.528
print(round(black76(84_000, 85_000, 0.14, 0.15, 30 / 365, margined=True)))  # 1004
```

## Где ошибаются

- **Подставлять простую или эффективную ставку.** В формуле $r$ — непрерывная ставка. 14% эффективных — это $\ln 1{,}14 = 13{,}1\%$ непрерывных, и на длинных опционах разница заметна.
- **Путать единицы $\sigma$ и $\tau$.** Годовая волатильность требует срока в годах. Дневная волатильность при сроке в годах занижает цену в $\sqrt{252}$ раз по $\sigma$.
- **Оценивать американский пут по формуле Блэка–Шоулза.** Формула европейская. Американский пут дороже, и для него нужно дерево или численное решение уравнения со свободной границей.
- **Считать допущения модели выполненными.** Волатильность не постоянна, цены прыгают, хедж дискретен и стоит денег. Модель — язык, на котором рынок котирует опционы через подразумеваемую волатильность, а не точное описание реальности. Этому посвящён модуль 9.
