# Приёмка, UAT и выпуск

QA подтверждает соответствие спецификации; UAT подтверждает, что решение подходит бизнес-процессу. Для записи UAT-пользователь проверяет не только «запись создана», но отмену, занятый слот, уведомление и видимость у администратора.

| Артефакт | Зачем нужен |
| --- | --- |
| Критерии приёмки | Что проверять в конкретной задаче |
| Чек-лист релиза | Миграции, фичефлаг, мониторинг, rollback |
| Release notes | Что изменилось и кого это касается |
| План поддержки | Кто разбирает ошибку и где смотреть traceId |

Фичефлаг снижает риск, если можно включить новый путь ограниченной аудитории. Но флаг — временный механизм: укажите владельца и дату удаления. Rollback не всегда означает откат кода: при необратимой миграции заранее выберите forward-fix и резервное копирование.

После релиза сверяйте метрику цели. Если онлайн-запись не уменьшила звонки, причина может быть не в API: возможно, пользователи не нашли кнопку или расписание пустое.
