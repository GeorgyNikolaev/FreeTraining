# Словарь данных и качество

Словарь данных устраняет «понятные всем» слова. Для каждого поля укажите тип, формат, источник, владельца, допустимые значения, обязательность и правила изменения.

| Поле | Тип/формат | Правило | Владелец |
| --- | --- | --- | --- |
| `starts_at` | UTC timestamp | Не в прошлом при создании | Сервис расписания |
| `status` | enum | `pending → confirmed/cancelled` | Сервис записи |
| `phone` | string E.164 | Валидируется при вводе | Профиль клиента |

Качество данных измеримо: полнота — у скольких записей заполнен телефон; уникальность — сколько дублей; актуальность — как быстро меняется статус; согласованность — совпадает ли статус в витрине и источнике.

Не маскируйте проблему «очисткой» без причины. Если найдены двойные активные записи, выясните путь возникновения: гонка запросов, ручной импорт, сбой интеграции. Затем добавьте ограничение, мониторинг и способ исправить уже испорченные данные.
