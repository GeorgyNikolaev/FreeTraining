# BPMN: читаем и строим понятные процессы

BPMN — стандартная нотация процессов: она должна быть понятна бизнесу и достаточно точна для команды. Используйте события для того, что произошло, задачи для работы, шлюзы для выбора пути.

```text
(Старт) → [Выбрать слот] → [Проверить доступность] → <Свободен?>
                                               ├─ да → [Создать запись] → (Подтверждено)
                                               └─ нет → (Показать другой слот)
```

| Элемент | Значение | Пример |
| --- | --- | --- |
| Start/End event | Начало/результат процесса | «Запрос получен», «Запись создана» |
| Task | Атомарная работа | «Создать запись» |
| XOR gateway | Ровно один путь | Слот свободен? |
| AND gateway | Параллельные пути | Отправить email и SMS |
| Pool/Lane | Участники и ответственность | Клиент / Сервис / Платёжный провайдер |

Message flow рисуют между разными pool, а sequence flow — внутри одного pool. Не используйте ромб для «этапа»: у шлюза всегда есть вопрос или условие на выходах.
