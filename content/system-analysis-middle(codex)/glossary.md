# Глоссарий

| Термин | Значение |
| --- | --- |
| Acceptance criteria | Проверяемые условия, по которым принимают конкретную задачу. |
| AS-IS / TO-BE | Фактический / целевой процесс. |
| Cache-aside | Паттерн, при котором приложение само читает и заполняет кэш при промахе. |
| C4 Container | Исполняемое приложение или хранилище на архитектурной диаграмме C4. |
| C4 Component | Логическая часть с отдельной обязанностью внутри Container. |
| DLQ | Очередь сообщений, которые не удалось обработать после ограниченных повторов. |
| Idempotency | Свойство, при котором повтор операции не меняет результат сверх первого выполнения. |
| NFR | Нефункциональное требование: измеримое свойство качества решения. |
| Outbox | Таблица/запись намерений отправить событие, сохраняемая в одной транзакции с бизнес-данными. |
| p95 | Значение метрики, ниже которого находится 95% измерений. |
| SLI / SLO | Измеряемый показатель услуги / его целевое значение. |
| Traceability | Связь потребности, требования, реализации и проверки. |
| UAT | Проверка бизнес-пользователем пригодности решения в реальном сценарии. |
| Webhook | HTTP-вызов, которым сервис уведомляет внешнего получателя о событии. |
| XOR gateway | BPMN-шлюз, из которого выбирается один путь по условию. |
