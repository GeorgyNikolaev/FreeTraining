# Домашнее задание: разбор реальной закупки

Цель — один раз пройти путь от опубликованных документов до строки данных руками, чтобы дальше понимать, что именно вы парсите.

## Что сделать

Найдите на `zakupki.gov.ru` **завершённый электронный аукцион по 44-ФЗ**, у которого было не менее трёх участников и есть хотя бы одна отклонённая заявка. Подойдёт любой: ограничьте поиск закончившимся периодом и способом «электронный аукцион».

Результат работы — две вещи.

**Первое: карточка закупки**, заполненная только из опубликованных документов. Минимальный набор полей:

| Поле | Откуда взято |
|---|---|
| Реестровый номер извещения | |
| Заказчик (ИНН, наименование) | |
| Код ОКПД2 и объект закупки | |
| НМЦК | |
| Размер обеспечения заявки | |
| Дата и время окончания срока подачи заявок | |
| Дата и время проведения торга | |
| Длительность торга | |
| Число участников, подавших заявки | |
| Итоговое предложение каждого участника | |
| Победитель (ИНН) и его цена | |
| Отклонённые участники и основания отклонения | |
| Дата протокола подведения итогов | |

Второй столбец обязателен: для каждого поля укажите, из какого именно документа оно взято. Если поля в документах нет — так и напишите, это и есть результат.

**Второе: список недоступного.** Выпишите пять признаков, которые вы хотели бы посчитать по этой закупке, но не можете, и укажите для каждого причину: поля нет в документах, поле есть, но пустое, или данные существуют только внутри площадки.

## Как проверить себя

- **Победитель взят из протокола подведения итогов, а не вычислен как минимум цены.** Если в вашей закупке это одно и то же лицо — хорошо, но в карточке всё равно должно быть указано, что источник именно протокол итогов. В выборке из десятков тысяч закупок эти два способа дадут разный ответ, и разница будет ровно там, где интереснее всего.
- **Дат минимум три, и они различаются**: окончание подачи заявок, проведение торга, подведение итогов. Если у вас получилась одна дата на всю закупку, вы смотрели только карточку закупки и не открывали протоколы.
- **Глубина снижения посчитана от НМЦК, а не от цены контракта.** Формула: `(НМЦК − цена победителя) / НМЦК`.
- **Длительность торга соотнесена с регламентом.** Четыре минуты означают, что ценовых предложений не было вовсе. Пять часов означают, что торг упёрся в предельную продолжительность. Любое значение между ними — это `4 + 4 × (число предложений)` минут с точностью до округления; если ваша арифметика не сходится, значит в протоколе раскрыты не все предложения, и это важное наблюдение о ваших будущих данных.
- **В списке недоступного нет пунктов вида «IP-адреса»**, если вы ограничились только ими. Пять пунктов — это требование заставить себя дойти до менее очевидных: состав собственников участника, его выручка, участие в закупках других заказчиков, история отклонений, наличие производственных мощностей.

## Типичная ошибка

Самая частая — взять закупку, где был один участник, и обнаружить, что считать нечего. Это не неудача: закупки с единственным участником составляют существенную долю массива и в скрининге обрабатываются отдельно, потому что признаки, основанные на сравнении участников между собой, для них не определены. Но для этого задания нужна закупка с торгом, поэтому ищите дальше.
