# Источники данных и их ограничения

Данные для вашей работы лежат в четырёх разных местах, и ни одно из них не отдаёт готовую таблицу. Этот урок — карта источников; следующий — практика получения главного из них.

## Главная новость: FTP больше нет

Почти вся русскоязычная литература, статьи и учебные материалы по анализу госзакупок описывают один путь: скачать архивы XML с FTP-сервера `ftp.zakupki.gov.ru`. **С 1 января 2025 года этот путь закрыт.** Информация и документы в машиночитаемом виде отдаются теперь через сервисы отдачи информации ЕИС.

Если вы читаете инструкцию, где фигурирует FTP, — она устарела целиком, включая описание структуры каталогов. Это первая вещь, которую стоит проверить в любом источнике по теме.

## Карта источников

| Источник | Что даёт | Как получить | Ограничения |
|---|---|---|---|
| ЕИС, сервисы отдачи информации | Извещения, протоколы, контракты в машиночитаемом виде | SOAP-запрос с токеном, в ответ — ссылка на архив | Нужен токен; форматы описаны в Альбоме ТФФ; объёмы большие |
| ЕИС, раздел «Открытые данные» | Наборы данных с паспортами, в том числе реестры | Скачивание наборов | Состав наборов ограничен, не всё покрывает |
| ЕИС, веб-интерфейс | Карточки закупок, документы процедур | Поиск на сайте, ручная выгрузка | Годится для десятков закупок, не для массива |
| База решений ФАС, `br.fas.gov.ru` | Тексты решений по делам — единственный источник меток | Поиск на сайте, далее разбор текстов | Программного интерфейса нет; тексты неструктурированы |
| Открытые данные ФНС и ЕГРЮЛ | Сведения о юридических лицах: руководитель, учредители, адрес, дата регистрации | Наборы открытых данных | Соединяется по ИНН; состав полей ограничен |
| Коммерческие агрегаторы | Готовые связи аффилированности, финансовые показатели | Подписка | Платно; для диплома обычно недоступно |

## Что брать из каждого

**ЕИС — ядро.** Отсюда весь массив закупок: кто, что, почём, с кем и когда. Без него работы нет.

**Решения ФАС — метки.** Других источников достоверной информации о состоявшихся сговорах не существует. Программного интерфейса у базы нет, поэтому предстоит разбор текстов: извлечение ИНН нарушителей и реестровых номеров закупок из мотивировочной части. Это отдельная небольшая задача обработки естественного языка, и закладывать на неё время нужно заранее.

**ЕГРЮЛ — фильтр.** Нужен ровно для одной цели, объяснённой в модуле 03: отделить согласованность внутри группы лиц от согласованности между независимыми конкурентами. Соединяется по ИНН.

**Агрегаторы — если повезёт.** Если у вашего вуза есть подписка на систему проверки контрагентов, готовые связи аффилированности сэкономят вам недели. Если нет — стройте связи сами по совпадению учредителей, руководителей и адресов из ЕГРЮЛ, отмечая в работе, что такой признак неполон.

## Оцените объём заранее

Прежде чем писать код, посчитайте, сколько данных вы собираетесь тянуть. Порядок величин по 44-ФЗ — миллионы процедур в год по стране. Выгружать всё для дипломной работы не нужно и вредно: объём вырастет до неуправляемого, а качество анализа не улучшится.

Разумный первый шаг — зафиксировать сегмент. Например: электронные аукционы по 44-ФЗ, один-два кода ОКПД2, два-три региона, период три-четыре года. Такая выборка обычно даёт десятки тысяч закупок — достаточно для устойчивой статистики и для построения осмысленного графа участников, и при этом обрабатывается на обычном ноутбуке.

Сегментация — не упрощение ради удобства, а методологическое требование: все относительные показатели, как показано в модуле 01, осмысленны только внутри сопоставимого сегмента.

## Правовая и техническая аккуратность

Данные ЕИС общедоступны, но это не значит, что их можно тянуть в любом темпе. В 2025 году доступ к массовой выгрузке был реорганизован и ограничен, и работа через сервисы отдачи предполагает идентификацию. Практические правила:

- используйте штатные сервисы отдачи, а не обход веб-интерфейса скриптом;
- соблюдайте разумный темп запросов и сохраняйте всё выкачанное локально, чтобы не запрашивать повторно;
- в дипломе укажите дату выгрузки — данные в ЕИС меняются задним числом при внесении изменений в контракты и пересмотре протоколов.

Последний пункт стоит запомнить отдельно: ваша выгрузка — это срез на дату, и через полгода тот же запрос вернёт другие цифры. Для воспроизводимости результатов срез нужно сохранить и зафиксировать.

## Что дальше

Следующий урок — практика получения данных из ЕИС: какой запрос отправить, что придёт в ответ и что с этим делать. Описание форматов меняется вместе с системой, поэтому опираться мы будем на два документа, актуальные версии которых лежат на самом `zakupki.gov.ru`: **Альбом ТФФ** (описание форматов файлов) и **инструкция по использованию сервисов отдачи информации ЕИС для юридических и физических лиц**.
