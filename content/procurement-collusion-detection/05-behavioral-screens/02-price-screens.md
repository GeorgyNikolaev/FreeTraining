# Ценовые скрининги

Набор показателей, вычисляемых из предложений участников одного лота. Основной корпус разработан для торгов с однократной подачей; ниже для каждого показателя указано, применим ли он к электронному аукциону.

## Обозначения

Пусть в лоте `n` участников, их предложения упорядочены по возрастанию: `b₍₁₎ ≤ b₍₂₎ ≤ … ≤ b₍ₙ₎`. Победившее предложение — `b₍₁₎`, `R` — начальная (максимальная) цена контракта.

## Показатели

| Показатель | Формула | Что ловит | Применим к аукциону |
|---|---|---|---|
| Глубина снижения | `(R − b₍₁₎) / R` | Торг не состоялся или был символическим | Да, основной |
| Разрыв до минимума | `(b_побед − b₍₁₎) / R` | Более дешёвые участники выбыли | Да, основной |
| Коэффициент вариации | `σ(b) / μ(b)` | Согласованные, слабо разбросанные предложения | Ограниченно |
| Размах | `(b₍ₙ₎ − b₍₁₎) / b₍₁₎` | Общий разброс предложений | Ограниченно |
| Относительная разница | `(b₍₂₎ − b₍₁₎) / b₍₁₎` | Победитель отделён от остальных | Ограниченно |
| Относительная дистанция | `(b₍₂₎ − b₍₁₎) / σ(b₍₂₎…b₍ₙ₎)` | Победитель далеко, проигравшие кучно | Ограниченно |
| Эксцесс и асимметрия | Моменты распределения `b` | Форма распределения предложений | Нет |
| Число ценовых предложений | Счётчик шагов торга | Пассивность при нескольких участниках | Только к аукциону |

**Относительная дистанция** (relative distance, RD) — самый содержательный показатель классического набора. Идея: при сговоре с ценами прикрытия проигравшие подают предложения «для галочки», и эти предложения кучкуются, а победитель отделён от них заметным интервалом. Показатель измеряет этот интервал в единицах разброса проигравших. Высокие значения — подозрительны. Показатель используется в работах Imhof, Karagök и Rutz по швейцарским строительным картелям и в исследовании Huber и Imhof о применении машинного обучения к скринингам (International Journal of Industrial Organization, 2019).

**Коэффициент вариации** при сговоре обычно **ниже**: координация снижает разброс, который должна была бы порождать независимость издержек участников.

## Почему половина таблицы помечена «ограниченно»

Показатели формы и разброса предполагают, что предложения участников — независимые реализации, отражающие их издержки. В электронном аукционе это не так: участник видит текущую минимальную цену и реагирует на неё. Разброс итоговых предложений здесь порождён динамикой торга, а не распределением издержек.

Практический вывод для диплома: считать эти показатели по аукционам можно, но интерпретировать их как в классической литературе — нельзя, и в работе это должно быть сказано прямо. Более того, разница в поведении показателей между аукционами и процедурами с однократной подачей — сама по себе хороший исследовательский вопрос, дающий работе содержательный раздел.

## Расчёт

```python
import numpy as np
import pandas as pd

def lot_price_screens(group: pd.DataFrame, nmck: float) -> pd.Series:
    b = np.sort(group["price"].to_numpy(dtype=float))
    n = len(b)
    winner_price = group.loc[group["is_winner"], "price"]
    winner_price = float(winner_price.iloc[0]) if len(winner_price) else np.nan

    out = {
        "n_bids": n,
        "drop_rate": (nmck - winner_price) / nmck if nmck else np.nan,
        "gap_to_min": (winner_price - b[0]) / nmck if nmck else np.nan,
    }
    if n >= 2:
        out["spread"] = (b[-1] - b[0]) / b[0]
        out["diff_p"] = (b[1] - b[0]) / b[0]
        out["cv"] = b.std(ddof=1) / b.mean() if n >= 2 else np.nan
    if n >= 3:
        losing_std = b[1:].std(ddof=1)
        out["rd"] = (b[1] - b[0]) / losing_std if losing_std > 0 else np.nan
    return pd.Series(out)
```

Три детали, из-за которых расчёт обычно ломается.

**Показатели определены не при любом числе участников.** Относительная дистанция требует минимум трёх предложений — иначе разброс проигравших считается по одному значению. Не подставляйте нули: используйте отсутствующее значение, иначе модель научится на артефакте.

**Нулевой разброс проигравших — реальная ситуация.** Если все проигравшие подали одинаковую цену, знаменатель обращается в ноль. Это не ошибка данных, а сильный сигнал сам по себе — стоит завести отдельный булев признак «все проигравшие подали одинаковую цену».

**Победителя берём из протокола итогов.** `b₍₁₎` и цена победителя — разные величины, и вся ценность показателя `gap_to_min` в том, что они могут не совпадать.

## Закон Бенфорда: осторожно

Закон Бенфорда описывает распределение первых значащих цифр в естественно возникающих числах и используется в аудите для поиска подтасовок. Соблазн применить его к ценам закупок велик, но есть два ограничения.

Цены в электронном аукционе **не свободны**: они получаются вычитанием шага, составляющего долю от начальной цены. Первые цифры таких чисел определяются механикой торга, и отклонение от закона Бенфорда здесь ничего не говорит о сговоре.

Начальная цена контракта, напротив, назначается заказчиком относительно свободно, и к ней закон применим. Но тогда вы проверяете гипотезу о манипуляциях с обоснованием начальной цены — то есть про заказчика, а не про сговор участников между собой. Это другая задача; включать её в работу можно, но как отдельный сюжет с отдельной формулировкой.

## Где ошибаются

**Считают показатели по лотам с одним участником.** Все ценовые показатели там либо не определены, либо вырождены. Такие лоты обрабатываются отдельно.

**Сравнивают абсолютные значения между сегментами.** Как показано в предыдущем уроке, каждый показатель перед использованием нормируется внутри сегмента.

**Переносят направление интерпретации из зарубежных работ без проверки.** Направление связи показателя со сговором установлено для конкретных рынков и конкретных типов торгов. На российских электронных аукционах оно может отличаться, и проверить это — часть вашей работы, а не предпосылка.
