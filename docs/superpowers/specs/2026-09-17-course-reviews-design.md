# Оценки и отзывы курсов — дизайн-документ

Дата: 2026-09-17
Статус: согласован

## 1. Что делаем

Пользователь ставит курсу оценку от 1 до 5 и по желанию пишет отзыв. Средняя
оценка и число оценок видны на карточке курса на главной и в шапке страницы
курса. Отзывы читаются во вкладке «Отзывы» на странице курса.

## 2. Правила

1. Один пользователь — один отзыв на курс. Повторная отправка перезаписывает
   его, а не создаёт новый. Иначе один человек сдвигает среднее сколько угодно.
2. Оценка обязательна, текст нет. Можно поставить одни звёзды.
3. Оставить или изменить отзыв можно только после прохождения минимум двух
   модулей: первый обычно вводный, второй — уже основная часть. Модуль пройден,
   когда пройдены все его уроки и сдан тест модуля, если он есть. В курсе из
   одного модуля достаточно пройти его.
4. Свой отзыв можно удалить всегда, даже если после сброса прогресса условие
   п. 3 перестало выполняться.
5. «Сбросить прогресс» отзыв не трогает: это не прогресс.
6. Выгрузка прогресса включает отзывы пользователя.

Важная оговорка. Сейчас в системе один пользователь (`local`), поэтому средняя
оценка равна вашей оценке, а в списке будет один отзыв. Модель сразу рассчитана
на нескольких пользователей: когда появятся аккаунты, менять ничего не придётся.

## 3. База данных

Новая таблица `course_review`. Существующие таблицы не меняются, новая создаётся
при старте через `create_all`, как и остальные.

| Колонка | Тип | Назначение |
| --- | --- | --- |
| `id` | int, PK | |
| `user_id` | str | автор |
| `course_id` | str | имя папки курса |
| `rating` | smallint, 1–5 | оценка, `CHECK` в базе |
| `text` | text, null | отзыв, пустая строка сохраняется как `null` |
| `created_at` | timestamptz | время первой отправки |
| `updated_at` | timestamptz | время последнего изменения |

Уникальность по паре `user_id` + `course_id`, индекс по `course_id`.

Средняя оценка не хранится, а считается запросом `AVG` / `COUNT` с группировкой
по курсу. Для каталога это один запрос на все курсы, а не по запросу на курс.
Среднее округляется до одного знака. Отзывы на курс, папку которого удалили,
остаются в базе и нигде не показываются.

## 4. API

Новый роутер `app/api/reviews.py`.

| Метод и путь | Назначение |
| --- | --- |
| `GET /api/courses/{course}/reviews` | Сводка и список отзывов |
| `PUT /api/courses/{course}/reviews/me` | Создать или изменить свой отзыв |
| `DELETE /api/courses/{course}/reviews/me` | Удалить свой отзыв |

Все три проверяют существование курса (`get_course_or_404`). `PUT` при
невыполненном условии п. 2.3 возвращает 403 с текстом «Отзыв можно оставить
после прохождения 2 модулей».

Тело `PUT`:

```json
{ "rating": 4, "text": "Хорошие задачи, мало примеров по опционам." }
```

Проверки: `rating` — целое от 1 до 5, без половинок; `text` — не длиннее 2000
символов, пробелы по краям обрезаются. Нарушение — 422.

Ответ `GET`:

```json
{
  "rating_average": 4.0,
  "rating_count": 1,
  "can_review": true,
  "modules_required": 2,
  "modules_completed": 3,
  "my_review": { "rating": 4, "text": "…", "created_at": "…", "updated_at": "…" },
  "reviews": [
    {
      "id": 1, "rating": 4, "text": "…", "is_mine": true,
      "author_progress_percent": 57, "created_at": "…", "updated_at": "…"
    }
  ]
}
```

Список отсортирован по `updated_at`, новые сверху. `user_id` наружу не отдаётся,
вместо него флаг `is_mine`. `author_progress_percent` — текущий процент
прохождения курса автором отзыва, считается на лету тем же расчётом, что и
прогресс на карточке курса (не снимок на момент отзыва). Пагинации нет: при одном пользователе она не нужна,
добавится вместе с аккаунтами.

`DELETE` при отсутствии отзыва возвращает 404.

Изменения в существующих схемах:

- `CourseSummary` и `CourseDetail` получают `rating_average: float | None` и
  `rating_count: int`. При отсутствии оценок — `null` и `0`.
- `ProgressExport` получает `reviews` — отзывы пользователя (курс, оценка, текст,
  даты).

## 5. Фронтенд

### 5.1 Новые компоненты `StarRating`, `StarRatingInput`, `TextArea`

Поля многострочного ввода в дизайн-системе не было, поэтому добавляется `TextArea`
с подписью и счётчиком символов.

Лежит в `components/ui/`, два режима:

- **Показ** — пять звёзд с частичной заливкой по среднему (4,3 → четыре полных,
  пятая на треть), рядом число и количество: `4,3 · 12 оценок`. Для экранного
  диктора — `aria-label="Оценка 4,3 из 5, 12 оценок"`.
- **Ввод** — пять кнопок-звёзд, `role="radiogroup"`, выбор мышью и стрелками,
  подсветка при наведении, фокус с клавиатуры, заблокированное состояние.

Цвет заливки — новый смысловой токен `rating` в `tokens.css` (в обеих темах
ссылается на янтарный примитив), пустые звёзды — `line-strong`. Изумрудный не
берём: он означает «верно» и «главное действие». Отдельный токен, а не
`warning`: звезда не предупреждение, и их цвет можно будет развести. Иконка —
`Star` из `lucide-react`. Компонент добавляется на страницу `/design`.

### 5.2 Главная, `CourseCard`

В нижней строке карточки рядом с «N модулей · M уроков» — компактный показ:
одна звезда и `4,3 (12)`. Если оценок нет — ничего не выводим, пустая
строка «нет оценок» на каждой карточке только шумит. Клик по оценке ведёт на
`/courses/{course}?tab=reviews`.

### 5.3 Страница курса

- **Шапка.** Под описанием, в строке с тегами — `StarRating` в режиме показа.
  Без оценок — ссылка «Оценить курс», открывающая вкладку отзывов (только
  когда оценивать уже можно).
- **Вкладки.** Добавляется «Отзывы» после «Термины», с числом: «Отзывы · 1».
  Активная вкладка синхронизируется с параметром `?tab=` в адресе, чтобы на
  отзывы можно было сослаться с главной. Сейчас вкладка хранится только в
  состоянии компонента.
- **Вкладка «Отзывы».**
  1. Блок «Ваш отзыв».
     - Условие не выполнено и отзыва нет: вместо формы `Callout` «Отзыв можно
       оставить после прохождения 2 модулей. Пройдено: 1».
     - Отзыва нет: `StarRating` в режиме ввода, поле текста со счётчиком
       `0 / 2000`, кнопка «Сохранить» — вторичная, потому что акцентное действие
       экрана уже «Продолжить курс». Кнопка заблокирована, пока не выбрана оценка.
     - Отзыв есть: звёзды, текст, дата, кнопки «Изменить» и «Удалить».
       «Изменить» превращает блок в форму с заполненными полями и кнопкой
       «Отмена». «Удалить» спрашивает подтверждение, как сброс прогресса.
  2. Список всех отзывов: звёзды, метка «Пройдено N%», текст, дата изменения,
     у своего — метка «Вы».
     Пустой список — `EmptyState` «Отзывов пока нет».

Ошибки сохранения и удаления показываются `Callout` в тоне `danger` над формой.

### 5.4 Данные

- Ключ запроса `reviews(courseId)`, хук `useReviews`, мутации `useSaveReview` и
  `useDeleteReview`.
- После мутации сбрасываются `reviews(courseId)`, `course(courseId)` и `courses`,
  чтобы среднее обновилось в шапке и на главной.
- Типы порождаются заново через `npm run api:types`, вручную не пишутся.

## 8. Не входит

- Модерация, жалобы, ответы на отзывы, лайки.
- Оценка отдельных уроков и модулей.
- Сортировка и фильтры списка отзывов, пагинация.
- Напоминание оценить курс после его завершения — отложено.
