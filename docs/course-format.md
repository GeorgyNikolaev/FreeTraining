# Формат курса

> Этот файл — технический справочник формата: что именно принимает платформа.
> Если нужно **собрать новый курс через ИИ**, приложите к запросу
> [`course-create-prompt.md`](course-create-prompt.md) — он самодостаточен и,
> кроме формата, содержит требования к содержанию, объёмам, домашним заданиям
> и тестам.

Курс — это папка внутри `content/`. Имя папки становится идентификатором курса и
частью адреса страницы, поэтому пишется латиницей. Все отображаемые названия
задаются внутри файлов и пишутся по-русски.

## Структура

```
content/<course-id>/
  course.yaml                 обязателен
  cheatsheet.md               необязателен
  glossary.md                 необязателен
  exam.yaml                   необязателен
  01-<module-id>/
    module.yaml               обязателен
    01-<lesson-id>.md         хотя бы один урок
    homework.md               необязателен
    quiz.yaml                 необязателен
```

Числовой префикс в именах папок модулей и файлов уроков задаёт порядок.
Сортировка строковая, поэтому префикс пишется двумя цифрами (`01-`, `02-`, …,
`10-`): при однозначном префиксе `10-` встанет раньше `2-`.

## course.yaml

```yaml
title: Основы Python
description: Одно-два предложения о курсе.
tags: [python, backend]
level: beginner        # beginner | intermediate | advanced
prerequisites:         # необязателен
  - Базовый Python
  - HTTP и REST
```

`level` говорит о глубине курса, `prerequisites` — о том, что нужно знать до
него. Это разные вещи: «средний уровень» не подсказывает читателю, что курс про
RAG требует Python, HTTP и понимания embeddings. Пункты — короткие строки, они
выводятся списком на странице курса.

## module.yaml

```yaml
title: Введение
```

## Урок

Обычный Markdown. Первый заголовок первого уровня становится названием урока в
интерфейсе, поэтому файл начинается с него:

```markdown
# Что такое Python

Текст урока.
```

## homework.md

Домашнее задание модуля. Обычный Markdown, как урок. Файл с этим именем уроком
не считается: он становится отдельным шагом курса между последним уроком модуля
и его тестом, виден в содержании курса и открывается по адресу
`/courses/<course-id>/<module-id>/homework`.

Работу никто не проверяет и в прогрессе она не учитывается — платформа только
показывает текст.

## quiz.yaml и exam.yaml

Один формат для теста модуля и для экзамена. Верный вариант помечается прямо в
списке:

```yaml
pass_score: 70
questions:
  - question: Текст вопроса
    options:
      - text: Вариант 1
      - text: Вариант 2
        correct: true
      - text: Вариант 3
    explanation: Почему этот ответ верный.
```

Формулировка верного ответа нигде не повторяется, поэтому разойтись с вариантом
она не может. Несколько пометок `correct: true` делают вопрос вопросом с
несколькими правильными ответами:

```yaml
    options:
      - text: Вариант 1
        correct: true
      - text: Вариант 2
      - text: Вариант 3
        correct: true
```

### Старая запись через answer

Продолжает работать, менять готовые курсы не нужно. Требует дословного совпадения
`answer` с вариантом, поэтому для новых курсов не рекомендуется:

```yaml
    options: ["Вариант 1", "Вариант 2", "Вариант 3"]
    answer: "Вариант 2"
```

Смешивать две записи в одном вопросе нельзя: либо у всех вариантов поле `text`,
либо все варианты — строки и есть `answer`.

## Правила проверки

- Хотя бы один вариант помечен `correct: true` — или задан `answer`,
  присутствующий среди `options`.
- Варианты не должны повторяться, их не меньше двух.
- `pass_score` — целое число от 0 до 100.
- В модуле хотя бы один урок.
- `title` в `course.yaml` обязателен; `title` в `module.yaml` необязателен — без
  него название берётся из имени папки.
- `level`, если указан, — одно из `beginner`, `intermediate`, `advanced`.
  Другое значение делает курс нечитаемым целиком.
- Урок без заголовка первого уровня получает название из имени файла, а на
  `/api/health/content` появляется предупреждение.
- Подкаталоги курса, в которых нет ни `module.yaml`, ни файлов `.md`, модулями
  не считаются и игнорируются — туда можно класть картинки и вложения.
  Но любой `.md` в такой папке (кроме `homework.md`) делает её модулем, и без
  `module.yaml` курс перестаёт загружаться.
- `homework.md` не заменяет урок: модуль, в котором нет ничего, кроме него,
  считается модулем без уроков.

Ошибки не ломают приложение: неисправный курс не попадает в каталог, а сообщение
с точным указанием файла выводится на странице `/api/health/content`.
